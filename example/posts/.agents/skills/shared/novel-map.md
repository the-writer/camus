# 小说创作脉络公共片段

> 供 `novel/<subtype>/outline-map.md` 共用。各子类型文件只写自己的结构地图、识别口径与专项检查；输入、公共输出块、检查清单与参考链接统一以本文件为准。

## 1. 通用输入

| 输入 | 说明 | 缺失时 |
|---|---|---|
| 记忆 | `.agents/memories/` 中的 `outline.md`、`characters.md`、`world.md`、`continuity.md` | 缺失时从正文与 `.workshop` 重建，并标注「推断」 |
| 用户记忆（可选） | `.agents/memories/user/<用户>.md` 中的创作偏好、节奏与审美参照 | 不存在时跳过，不视为错误 |
| 正文 | `posts/`（不存在则 `src/`）下的卷 / 篇 / 章文件 | 无正文时按「只有大纲」模式分析，明确说明覆盖范围 |
| 主 `SUMMARY.md` | 站点元信息与目录结构 | 缺失时只按文件路径与标题分析 |
| `.workshop/`（可选） | 设定卡、地名、关系、候选与图谱，见 `workshop.md` | 不存在时跳过，不视为错误 |
| 分析目标 | 复盘、开新卷 / 开新篇、查断线、交接 | 未指定时按「全景复盘 + 下一步建议」执行 |

## 3. 通用质量检查清单

- [ ] 进度数据都有来源，未知项标了「未记录」，没有估算冒充统计；
- [ ] 每条线索与伏笔都记录了埋点、最近推进与回收状态；
- [ ] 人物弧线与出场章对得上，长期失踪人物已列出；
- [ ] `.workshop` 存在时已完成交叉核对，不存在时没有编造卡片内容；
- [ ] 冲突按「正文 > 用户指令 > 记忆 > `.workshop`」处理并标注；
- [ ] 「下一步」不超过 3 件，且按优先级排序；
- [ ] 未把推断写成作者设定，未虚构未提供的输入。
