# `.workshop/` 资产库契约

> 项目根存在 `.workshop/` 时，小说技能把它作为**创作资产库**一并读取；不存在就整节跳过，不视为错误。本文件是唯一契约来源，技能文件只引用，不重复文件表。

## 1. 文件与读取方式

| 文件 | 内容 | 读取方式 / 用途 |
|---|---|---|
| `project.md` | 项目总览、设定、总纲 / 章节清单 | 纯 Markdown；对照总纲与分析范围，它可能是计划，不等于正文进度 |
| `overview.md` | 总览 | 可为空，空文件跳过 |
| `sheets.md` | 设定卡：人物名、族群、性别、职业、籍贯、关系、备注 | `##` 分卡，`- 字段: 值` 取字段；建人物与关系底账 |
| `places.md` | 地名、族群、备注、结构 | 同上；建地点底账 |
| `relations.md` | 关系：来源 / 目标 / 关系类型 | 同上；校验人物关系与图谱连线 |
| `candidates.md` | 名称候选：族群、类型、性别、稀有度、字数、来源、收藏 | 同上；找尚未使用的命名资产 |
| `graph.md` | 节点数、连线数、节点 / 连线快照、布局坐标 | Markdown 列表与表格；核对数量、孤儿节点与孤立设定 |
| `preferences.md` | 生成规则、候选库筛选条件 | JSON 代码块；只作生成偏好，不作情节事实 |
| `sheets.ini` | 人物 / 候选速查 | INI：`[人物]`、`[候选]` 分节，`名称 = 备注`；与 `sheets.md` 冲突时以 `sheets.md` 为准 |

## 2. 使用规则

- **只读**：AI 不修改 `.workshop/`，由外部「创作工坊 / Creation Workshop」维护。
- **不是事实来源**：与正文冲突时以正文为准，并把差异记入 `continuity.md`。
- **冲突优先级**：正文 > 用户新指令 > `.agents/memories/` > `.workshop/`；冲突处必须标注，不静默采信任何一方。
- **不编造**：文件不存在、字段为空或读不到时标「无 / 未记录」，不虚构卡片内容。
- **写回**：核对结论写回 `.agents/memories/`（`outline.md`、`characters.md`、`world.md`、`continuity.md`），不写回 `.workshop/`。

## 3. 交叉核对

固定核对四类差异：

1. 正文有、卡片没有；
2. 卡片有、正文没用；
3. 关系不一致；
4. 候选 / 地标闲置。

输出表模板与章节位置见 `novel-map.md` 的「`.workshop` 交叉核对」。
