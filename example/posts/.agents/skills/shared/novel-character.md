# 小说人物档案公共片段

> 供 `novel/<subtype>/character-bible.md` 共用。子类型文件只写自己的专项（境界 / 金手指、队伍 / 种族 / 信仰、生活细节等）；以下通用块与写法不重复。

## 1. 动机链模板

```text
外在目标：<可被外部观察的目标，别人看得见他在追什么>
内在需求：<他自己说不清、但真正缺的东西>
恐惧    ：<最怕发生的那件事>
错误信念：<他坚信、但站不住脚的判断>
秘密    ：<瞒着别人的事，一旦暴露会怎样>
代价    ：<不改变信念就要失去的东西>
转变触发：<哪个具体事件逼他承认信念是错的>
新常态  ：<转变之后他成了什么样的人>
```

要求：外在目标 ≠ 内在需求；六项缺一不可，缺项写「待补」。转变必须有触发事件与代价，不能顿悟。

## 2. 关系网写法

用**功能**描述关系，不用**标签**描述关系：

| 标签写法（不可用） | 功能写法（可用） |
|---|---|
| A 和 B 是朋友 | A 需要 B 给 B 说不出口的勇气；B 需要 A 提供的钱 |
| A 是 B 的敌人 | A 怕 B 手里那份记录；B 需要 A 别把事情闹大 |
| A 是 B 的同事 | A 要 B 替自己顶班；B 要 A 承认流程是他改的 |

附加要求：关系必须**双向且不对称**——A 要 B 给的 ≠ B 要 A 的。关系变化时同步检查称谓。

## 3. 语言与称谓通用维度

| 维度 | 写法 | 检验 |
|---|---|---|
| 语速与句长 | 短促 / 拖长；单句多 / 从句多 | 遮住人名能认出是谁吗 |
| 常用词与口头禅 | 具体到可模仿的词或句式 | 换个角色说还成立吗 |
| 称谓习惯 | 对长辈 / 平辈 / 下属分别叫什么 | 与关系变化同步过吗 |
| 方言与行话 | 只列真正会出现在口中的词 | 换角色是否失效 |
| 回避与沉默 | 什么话题他不接、怎么岔开 | 沉默是否被写出来 |
| 情绪外露 | 哭 / 骂 / 沉默 / 手上的动作 | 越激动越沉默的人被写对了吗 |

## 4. 工具人与功能检查

对每个配角问三句：

1. 删掉他，这本书 / 这一卷损失什么？
2. 他有独立于主角的诉求或困境吗？
3. 他有可被记住的行为、语言或外形吗？

答不上来的列入「合并 / 删除建议」，不要留在总表里当背景板。

## 5. 通用一致性检查

| 检查 | 通过标准 |
|---|---|
| 行为可解释 | 每个关键行为都能追溯到动机链中的某一项 |
| 目标与需求不同 | 外在目标 ≠ 内在需求；相同即人物扁平 |
| 信念驱动决策 | 错误信念能解释至少两次错误决策 |
| 秘密有代价 | 秘密一旦暴露会造成真实损失 |
| 关系非对称 | 每组关系都是双向且不对称的 |
| 配角有功能 | 每个配角至少承担一项功能，否则列入合并或删除 |
| 语言可辨 | 同一场景遮住人名能认出说话人 |
