# 西幻旅程分卷与章节大纲（novel/western-illusion）

> 把西幻故事核展开成旅程级结构：分卷、旅程阶段、地标锚点、探索与战斗交替、BOSS 阶梯与回报。

## 用途

- 排出「受雇 → 启程 → 试炼 → 深入 → 回归 → 余波」式的完整旅程骨架。
- 用地标与补给把行程写实，避免「上一章在北境、这一章就到南境」的漂移。
- 让探索与战斗交替出现，避免连续遭遇战或连续赶路带来的节奏塌陷。
- 给 BOSS 阶梯配上看得见的回报（战利品、声望、情报、关系），让升级有依据。

## 何时使用

- 开写长篇或系列、决定分卷时；
- 「中段塌陷」「一直在赶路」「打怪打到麻木」时；
- 需要把已有草稿重新编排为旅程结构时；
- 计划第二部 / 续作路线时。

## 创作进度

> 本技能的第一步是进度回顾：从 `.agents/memories/` 与作品数据源汇总「写到哪、写了多少、还差什么」，再进入具体工作。口径与模板见 `AGENTS.md` §5.4。

### 回顾步骤

1. **读记忆**：先读 `.agents/memories/project.md`、`outline.md`，再按需读 `characters.md`、`world.md`、`continuity.md`、`preferences.md`、`style.md`；目录或文件不存在就跳过，不视为错误。
2. **扫数据**：扫描源目录（`posts/`，不存在则 `src/`）的卷 / 章文件；若存在 `.workshop/`，按 `AGENTS.md` §5.5 读取设定卡、地名、关系与候选条目。
3. **统计**：按下表统计卷 / 章 / 字数、最近更新、伏笔回收、人物与设定条目；所有数值给出「来源」，无法从文件得到时标「未记录」，不估算、不编造。
4. **对齐**：记忆与正文冲突时以正文为准；回顾结论写回 `outline.md`（进度、伏笔）及受影响的类别文件。
5. **输出回顾**：先交付「进度回顾」块，再继续本技能后续的输入与执行步骤。

## 输入

| 输入 | 说明 | 缺失时 |
|---|---|---|
| 一句话梗概 / 故事核 | 旅程要去哪里、解决什么 | 必须有 |
| 世界设定基线 | 地理、势力版图、magic system 边界 | 缺失时先做 `premise-generator.md`，或从正文抽取并标注「推断」 |
| 人物档案 | 队伍分工、位阶与弧线节点 | 缺失时先做 `character-bible.md` |
| 目标篇幅与分卷数 | 决定章数、卷长与节奏密度 | 未指定时按「长篇 30 万字 / 3 卷 / 每卷 20 章」假设并说明 |
| 结局形态 | 本卷终点 / 全书终点 / 开放式 | 向用户确认或给 2 个候选 |

## 执行步骤

1. **定旅程轴**：写出「起点 → 终点」与「旅程中要穿过的地理层级」，明确队伍为什么必须走这条路。
2. **切六阶段**：把故事放进受雇 / 启程 / 试炼 / 深入 / 回归 / 余波，标出每阶段的起止章。
3. **铺地标锚点**：每个阶段选 1–3 个地标（城镇、遗迹、关隘、营地、航线），给每个地标写「能提供什么、缺什么、有什么风险」。
4. **标行程耗时**：从地标到地标写天数、补给消耗、季节或路况影响，写进大纲而不是留白。
5. **交替探索与战斗**：排「探索 → 战斗 → 探索」的节拍，给每场战斗一个它推进的任务（拿到线索 / 争取时间 / 换取通行），不写无目的遭遇战。
6. **搭 BOSS 阶梯**：按难度递增排列守卫 → 精英 → 次级首领 → 终局 BOSS，各自对应一次能力或资源升级。
7. **配回报**：给每场胜利标出战利品、声望、情报、关系四类回报中的至少一类，写明用途。
8. **挂弧线与伏笔**：把人物弧线节点与伏笔挂到具体章。
9. **体检**：跑「旅程结构自检表」，失衡就调阶段长度与战斗位置，而不是靠加戏补救。

## 旅程六阶段

| 阶段 | 章节占比（长篇参考） | 目标 | 典型内容 | 结束标志 |
|------|-------------------|------|---------|---------|
| 受雇 | 5–10% | 拿到委托、认识队伍 | 委托来源、报酬分歧、拒绝的理由 | 契约签下或明确拒绝 |
| 启程 | 5–10% | 离开日常、暴露不兼容 | 准备补给、第一次摩擦、路线选择 | 队伍出发，回不去了 |
| 试炼 | 15–20% | 用小规模挑战验证设定与队伍 | 边境冲突、低阶遗迹、第一次真正的代价 | 证明能活着继续 |
| 深入 | 35–45% | 全书核心区域，压力最高 | 迷径地牢 / 深部遗迹 / 势力腹地 | 抵达并触发终局 |
| 回归 | 15–20% | 带着后果回来 | 撤离、追兵、代价结算 | 回到文明区或安全地 |
| 余波 | 5–10% | 落地后果、分配回报 | 战利品归属、声望兑现、伏笔收束 | 新常态确立 |

> 占比是参考值，允许浮动；重点是**顺序与功能**正确，以及每一阶段都有明确的进入条件与退出条件。

## 地标与场景锚点

| 地标 | 类型 | 能提供 | 缺什么 | 风险 | 首次出现章 |
|------|------|--------|-------|------|-----------|
| <...> | <城镇 / 驿站 / 遗迹 / 关隘 / 营地 / 航线> | <补给 / 情报 / 修理 / 通行> | <...> | <...> | 第 N 章 |

**地标使用规则**

- 每个地标至少用两次：一次作为「听说 / 提及」，一次作为「抵达 / 后果」；
- 地标之间必须有**中间地带**（荒野、林地、边境、封锁区），不要让队伍从一个城镇直接出现在另一个城镇；
- 地标状态会变：被洗劫、被封锁、被某个势力接管——变化必须写出来，否则世界是静止的。

## 行程与后勤

| 项 | 要写清的内容 |
|---|---|
| 距离与天数 | 地标 A 到 B 需要几天，走哪条路，是否有捷径 |
| 补给 | 食物、水、药剂、马匹草料消耗多少；补给点在哪 |
| 交通 | 步行 / 驮马 / 马车 / 传送阵（若存在，代价与限制是什么） |
| 季节与天气 | 当前季节对路况、作物、疾病、能走哪条路的影响 |
| 信息 | 消息从发出到抵达要多久，急信有多快 |

> 「传送阵」这类超常交通必须写清**代价与限制**（消耗、距离上限、目的地数量），否则它会掏空整个旅程的地理压力。

## 探索与战斗交替

| 节拍 | 功能 | 篇幅配比（参考） | 注意 |
|------|------|----------------|------|
| 探索 | 给线索、给地形、给未知 | 探索 : 战斗 ≈ 2 : 1（可反） | 探索必须有**可获得的东西**，否则就是赶路 |
| 战斗 | 兑现前面的伏笔、消耗资源 | 每场 ≤ 1/3 卷 | 每场战斗至少改变一个状态（人员、物资、声望、情报） |
| 过渡 | 消化后果、决定去向 | 短 | 不要把过渡写成复述 |
| 关键战斗 | 阶段 BOSS | 每阶段 1–2 场 | 必须有观众（有人在看、有人记着） |

> 连续三场战斗之间必须插一段非战斗；连续三段探索之间必须插一次风险事件。

## BOSS 阶梯与回报

| 阶梯 | 定位 | 实力区间（相对位阶） | 打法要求 | 回报 | 后续影响 |
|------|------|------------------|---------|------|---------|
| 守卫 | 闸口 / 巡逻 / 契约仆从 | 低于队伍均值 | 试探、消耗、绕行 | 小额物资、情报 | 打开通路 |
| 精英 | 精英怪 / 军官 / 家族私兵 | 队伍均值 | 需要配合与位置 | 关键道具、声望 | 得罪某个势力 |
| 次级首领 | 守门者 / 地方强豪 / 异化生物 | 略高于队伍均值 | 需要准备与消耗 | 重要线索、地图、盟友 | 改变路线 |
| 终局 BOSS | 幕后 / 古龙 / 禁术使用者 | 高于队伍均值一档 | 靠已铺垫的能力与代价 | 真相、核心遗物 | 走向回归与余波 |

**回报规则**

- 每次胜利至少给**一种**可见回报（战利品 / 声望 / 情报 / 关系），不给回报的胜利等于没打；
- 战利品要**有后续用途**：在后面被用掉、被交易、被拒绝、被抢走；
- 声望回报要能被世界听见：出现「你们是那支队伍」这类后续反应；
- 越级战胜必须留下代价（伤、耗损、暴露位置、欠人情）。

## 旅程结构自检表

| 检查 | 通过标准 |
|------|---------|
| 六阶段齐备 | 受雇 / 启程 / 试炼 / 深入 / 回归 / 余波各自有进入与退出条件 |
| 地理连贯 | 每个地标可从上一个抵达，路径与耗时写在案 |
| 节奏交替 | 没有连续三场战斗或连续三段纯赶路 |
| 战斗有任务 | 每场战斗推进线索、时间、通行或资源之一 |
| 回报可见 | 每场胜利至少给一种可见回报，且有后续用途 |
| 位阶匹配 | BOSS 实力与队伍位阶匹配，越级处写了代价 |
| 弧线挂载 | 人物弧线节点落在具体章 |
| 伏笔闭合 | 每条伏笔有回收点或明确标注「留白」 |

## 质量检查清单

- [ ] 六个旅程阶段齐全，每段有进入条件与退出标志；
- [ ] 地标之间的行程天数、补给与交通方式写在案，可核算；
- [ ] 探索与战斗交替，没有连续三场战斗或三段纯赶路；
- [ ] 每场战斗都推进了线索、时间、通行或资源之一；
- [ ] BOSS 阶梯实力递增，越级处写了代价与后续影响；
- [ ] 每次胜利都有可见回报，且战利品在后续被用掉或产生后果；
- [ ] 人物弧线与伏笔都挂到了具体章，伏笔账本闭合；
- [ ] 未虚构地名、销量、榜单或「某作品就是这样」类来源。
