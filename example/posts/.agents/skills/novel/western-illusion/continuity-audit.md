# 西幻世界设定连续性审查（novel/western-illusion）

> 用「规则台账 + 位阶台账 + 地理与行程台账 + 势力台账 + 时间轴 + 伏笔账本」，检查西幻长篇是否自洽。

## 用途

- 系统校对魔法规则、位阶、地图、势力与时间线，找出前后矛盾。
- 发现「作者自己记错了」的硬伤：旅行耗时、补给、伤势、称谓、禁术后遗症。
- 检查设定通胀：新能力、新材料、新势力是否落在体系预留的空位里。
- 检查传说中的承诺是否兑现，史书与正文是否互相打脸。

## 何时使用

- 每写完一卷 / 每 5–10 万字做一次；
- 连载或出版前终审；
- 读者提出「魔法规则前后不一」「上一章还在北境」时；
- 多主角队伍、多线叙事交错的章节写完后。

## 输入

| 输入 | 说明 | 缺失时 |
|---|---|---|
| 全部正文 | 或分卷文本 | 必须有 |
| 世界设定基线 | magic system 六要素、位阶标尺、种族与势力、地标 | 缺失时先做 `premise-generator.md`，或从正文抽取并标注「推断」 |
| 人物档案 | 位阶、职业、信仰、称谓 | 缺失时先做 `character-bible.md` |
| 章节顺序 | 叙事顺序 vs 故事时间 | 从正文抽取 |
| 地图 / 行程记录 | 地标之间的距离与耗时 | 从正文抽取，缺失处标「待补」 |

## 执行步骤

1. **建规则台账**：逐次记录 magic system 的使用——谁、在哪、用了什么、准备多久、消耗什么材料、付出什么代价、结果如何。
2. **查可推演性**：同一规则在不同章的使用是否一致；关键结果能否由台账里的规则推出；是否有临时新增的例外。
3. **建位阶台账**：记录每个角色的位阶与当场表现，检查越阶是否有代价，同层内是否有数量级差异。
4. **建地理与行程台账**：记录地标之间的距离、交通方式、耗时、季节与补给消耗，找出地图漂移。
5. **建势力台账**：记录各势力的资源、底线、结盟与冲突，检查「刚结盟就翻脸」这类无过渡的矛盾。
6. **建时间轴**：把事件按故事时间排序，标出叙事顺序（章节号）与故事时间的对应关系。
7. **查信息越界**：限知视角下角色是否用了他不可能知道的信息（没在场、没听说、没读到）。
8. **查伏笔与传说**：每个伏笔与传说是否有埋点与兑现；兑现是否兑现了当初承诺的内容。
9. **分级输出**：致命 / 显要 / 轻微，并给出具体改法。

## 严重度分级

> 通用分级与公共输出 / 检查基线见 `.agents/shared/novel-continuity.md`；本技能只补规则、位阶、地理与势力专项。

## 常见连续性风险清单（西幻）

- **魔法规则**：施法代价、准备时间、材料与冷却是否按台账执行；禁术是否只是「很贵」而不是「不可做」；
- **位阶**：同层内表现可比；越阶有可指认的代价；没有解释的跳级要单独列出；
- **地理**：地标之间的耗时与路线；传送类手段的代价与限制是否被滥用；
- **补给与货币**：食物、水、药剂、马匹草料、钱币单位与购买力；
- **伤势与恢复**：伤口位置、恢复时间、治疗手段的可得性；
- **势力关系**：结盟、背叛、封锁是否有前置事件；势力底线是否被无声突破；
- **神系与教会**：教义、禁忌、神职层级、对禁术的态度是否前后一致；
- **种族特征**：寿命、感官、语言、偏见是否稳定，不被临时赋予新能力；
- **称谓与语域**：爵位、军职、敬称与关系的对应；不同势力对同一人的称呼差异；
- **信息与视角**：角色通过什么途径得知信息（在场？信件？传闻？）；
- **传说与史书**：正文事件与「千年前的大战」这类传说是否互相打脸；
- **伏笔**：埋下时承诺的信息与回收时的信息是否一致。

## 质量检查清单

- [ ] 规则台账覆盖了所有关键施法，且标出能否由已写规则推出；
- [ ] 位阶台账覆盖主要角色，越阶处都检查了代价；
- [ ] 地理与行程台账能核算出「从 A 到 B 要几天」，图表与正文一致；
- [ ] 势力关系的变化都有前置事件，没有无声翻脸；
- [ ] 每个问题都标注了级别、位置与可执行的改法；
- [ ] 伏笔与传说都有状态（已回收 / 留白 / 待埋），没有把推断当成作者设定；
- [ ] 限知视角的信息越界已单独列出；
- [ ] 已按 `.agents/shared/novel-continuity.md` 的通用检查清单逐条自检。
