# 西幻核心设定与魔法体系（novel/western-illusion）

> 产出西幻世界的可推演设定核：一句话卖点、magic system、种族与势力版图、禁忌与悬念。

## 用途

- 在动笔前把「西幻灵感」落成可写、可检验、可延展的设定集。
- 建立 magic system 的硬边界，让读者能依据已写规则**推演**后续战斗结果。
- 让种族与势力以利益结构出现，而不是善恶标签。
- 在多个设定方向之间做取舍，避免写到中途发现体系漏洞。

## 何时使用

- 开新坑、决定「这个世界到底是什么样」时；
- 写到中段发现魔法越写越随意、危机只能靠临时设定解决时；
- 需要为系列 / 多卷作品统一设定基线时；
- 需要把世界规则讲清楚（写设定集、序章大纲、给同伴对齐）时。

## 创作进度

> 本技能的第一步是进度回顾：从 `.agents/memories/` 与作品数据源汇总「写到哪、写了多少、还差什么」，再进入具体工作。口径与模板见 `AGENTS.md` §5.4。

### 回顾步骤

1. **读记忆**：先读 `.agents/memories/project.md`、`outline.md`，再按需读 `characters.md`、`world.md`、`continuity.md`、`preferences.md`、`style.md`；目录或文件不存在就跳过，不视为错误。
2. **扫数据**：扫描源目录（`posts/`，不存在则 `src/`）的卷 / 章文件；若存在 `.workshop/`，按 `AGENTS.md` §5.5 读取设定卡、地名、关系与候选条目。
3. **统计**：按下表统计卷 / 章 / 字数、最近更新、伏笔回收、人物与设定条目；所有数值给出「来源」，无法从文件得到时标「未记录」，不估算、不编造。
4. **对齐**：记忆与正文冲突时以正文为准；回顾结论写回 `outline.md`（进度、伏笔）及受影响的类别文件。
5. **输出回顾**：先交付「进度回顾」块，再继续本技能后续的输入与执行步骤。

## 输入

| 输入 | 说明 | 缺失时 |
|---|---|---|
| 灵感碎片 | 一句话、一个画面、一种「想要的感觉」 | 必须有（哪怕只有一句） |
| 类型取向 | High fantasy / Sword and sorcery / Hard fantasy / 低魔等 | 向用户确认，或按「类型取向速查」给 3 个候选 |
| 篇幅与形态 | 长篇 / 中篇 / 短篇 / 系列 / 同人衍生 | 未指定时按「长篇 30 万字、单卷」假设并说明 |
| 魔法基调 | 「清晰可推演」还是「神秘不可解」 | 向用户确认；默认取「清晰可推演」 |
| 既有设定 | 已有的种族、势力、禁忌、命名 | 扫描已有文本抽取，标注「推断」 |
| 边界 | 不写什么（尺度、宗教敏感、恐怖元素） | 向用户确认 |

## 执行步骤

1. **定类型取向**：明确属于哪一类西幻子类型，写下读者默认期待的 obligatory 场景。
2. **写世界一句话卖点**：句式「在 <世界的可感特征> 下，<谁> 必须 <行动>，否则 <代价>」。
3. **搭 magic system 六要素**：来源 / 位阶 / 施法代价 / 准备时间与冷却 / 材料与媒介 / 禁术与禁忌，六项缺一不可。
4. **定硬边界**：写清至少三条「在本世界物理或规则上做不到的事」，而不是「暂时没遇到」。
5. **立实力标尺**：按「凡人 → 术士 → 施法者 → 高位者 → 传奇 → 禁术」分层，每层给可比较刻度与越阶代价。
6. **排种族与人种**：每个种族写「生存方式 + 偏见 + 禁忌 + 内部矛盾」，禁止单一善恶标签。
7. **画势力版图**：为王国、教会 / 神系、学院、公会、佣兵团、贵族议会各写「资源 / 底线 / 核心冲突 / 可交换的东西」。
8. **定禁忌与悬念**：列 5 条读者会追问但暂不回答的问题，为每条指定埋点位置与兑现窗口。
9. **列三个备选方向**：同一核心卖点下三种 magic system 取向，标注各自成本与风险。
10. **自检**：跑「西幻设定自检表」，不通过项写清处理方式。

## 类型取向速查

| 取向 | 世界重心 | 读者默认期待 | 写作难点 |
|------|---------|-------------|---------|
| High fantasy | 族群兴衰、王权更替、跨地域格局 | 史诗尺度、群像、秩序与传统的重量 | 格局过大导致主角失焦 |
| Sword and sorcery | 个人冒险、财富与危险并置 | 队伍、遗迹、战利品、势均力敌的对手 | 容易滑向「刷副本」 |
| Hard fantasy | 魔法稀有且有代价，世界不为主角让步 | 规则严守、代价真实、凡人不被拯救 | 主角困境易重复，需靠外部变量破局 |
| 低魔 / 灰色地带 | 魔力稀薄或被垄断，异象不予解释 | 悬疑感、不可靠的奇幻、现实的重量 | 「不解释」容易写成含糊 |

> 取向是本作品的写作约定，不是对任何具体作品的描述；文档里写「本世界按 <取向> 的约定处理」这类表述。

## 魔法体系模板

### 六要素

| 要素 | 要回答的问题 | 常见写法（通用） | 失效信号 |
|------|------------|----------------|---------|
| 来源 | 魔力从哪来、谁能接触 | 天生血脉 / 自然环境 / 契约 / 学徒训练 / 神授 | 来源说不清，能力却随取随用 |
| 位阶 | 强弱怎么分、怎么比 | 分层分级，每层给可观察的能力表现 | 同层内无法比较，或随时跨层 |
| 施法代价 | 用了会失去什么 | 生命 / 记忆 / 寿命 / 契约 / 声望 / 关系 | 代价可忽略，力量可以白嫖 |
| 准备时间与冷却 | 多久能再施一次 | 手势与咒语耗时、法力枯竭、需静置 | 连续施法无消耗，战斗失去博弈 |
| 材料与媒介 | 需要什么才能用 | 银粉、血、符纸、特定器物、祭品 | 材料被临时新增（设定通胀） |
| 禁术与禁忌 | 什么绝对不能做 | 献祭、篡改因果、唤名、灵魂交易 | 禁术只是「很贵」而不是「不可做」 |

### 位阶标尺

| 层级 | 能力表现（通用描述） | 相对刻度 | 越阶代价 |
|------|-------------------|---------|---------|
| 凡人 | 无超凡能力，靠技艺、装备、协作与情报 | `<基线刻度>` | 靠组织与地形补位 |
| 术士 | 单类小术，需材料或完整手势 | `<刻度>` | 脆弱、被针对；施法中断即失效 |
| 施法者 | 稳定战术用法，能改变一场遭遇战 | `<刻度>` | 消耗可见，被针对材料与视野 |
| 高位者 | 可改变一片区域内战局 | `<刻度>` | 需准备、媒介、盟友掩护；极少独行 |
| 传奇 | 出现在史书与传说中的规模 | `<刻度>` | 罕见，通常已成历史事件或传说 |
| 禁术 | 越过体系边界的手段 | 无刻度 | 必付不可逆代价，且留下可追溯痕迹 |

> 刻度必须**可比较**：同一层级内两名角色对同一手段的结果不应有数量级差异；越阶必须有可指认的代价（时间、材料、人命、名声），且事后有人记得。

### 硬边界写法

- 正向写「能做什么」，同时必须写出至少三条**做不到**的事；
- 边界要落在来源、代价、准备时间这三项之内（最容易被作者临时放宽的三处）；
- 每条边界给出它在剧情中的首次可见处，避免规则只存在于设定集。

## 种族与势力设计表

### 种族四问

| 问题 | 说明 | 避免 |
|------|------|------|
| 生存方式 | 他们靠什么活下来（地理、聚落、技术） | 无来由地长寿 / 灵巧 |
| 偏见 | 他们普遍看不起谁，依据是什么 | 把偏见当事实真相 |
| 禁忌 | 什么行为会让他们拒绝、驱逐或仇视 | 仅有装饰性习俗 |
| 内部矛盾 | 本族内部哪一派与哪一派对立 | 全族同声同气 |

> 上表的「生存方式」「偏见」只是常见处理方向，不是种族设定的事实来源；写到具体种族时以本世界自己的设定为准。

### 势力四问

| 问题 | 说明 |
|------|------|
| 资源 | 它真正握在手里的东西（钱、地、军队、情报、魔法垄断） |
| 底线 | 它宁可不做什么（越线会失去什么） |
| 核心冲突 | 与哪个势力因什么资源冲突 |
| 可交换的东西 | 它愿意用什么换什么（结盟关系由此成立） |

> 势力之间是利益冲突与结盟关系，不是善恶阵营。写下的是「它要什么、它怕失去什么」，不是「它是好人」。

## 西幻设定自检表

| 检查 | 通过标准 |
|------|---------|
| 一句话卖点可复述 | 含「特征 / 行动 / 代价」三要素，能一句话讲清 |
| magic system 可推演 | 读者能依据已写规则预测某个角色施法的结果与代价 |
| 六要素齐备 | 来源 / 位阶 / 代价 / 准备与冷却 / 材料 / 禁术全部有答案 |
| 硬边界存在 | 至少三条做不到的事，且在正文可见处出现过 |
| 种族非单标签 | 每个种族同时有生存方式、偏见与内部矛盾 |
| 势力有底线 | 每个势力写得出「宁可不做什么」 |
| 悬念可兑现 | 每条悬念都有埋点位置与兑现窗口，不是永远不答 |
| 无设定通胀 | 新设定只落在体系预留的空位里，未被临时发明 |

## 质量检查清单

- [ ] 一句话卖点里同时有「世界特征 / 人物行动 / 失败代价」；
- [ ] magic system 六要素全部有答案，缺项已标注「待补」而不是留空；
- [ ] 至少写清三条硬边界，且都不是「暂时没遇到」；
- [ ] 位阶层级之间可比较，越阶都有可指认的代价；
- [ ] 每个种族都有内部矛盾，没有被写成单一善恶标签；
- [ ] 每个势力都写得出自己的底线与可交换物，不是善恶阵营标签；
- [ ] 每条悬念都有埋点位置与兑现窗口；
- [ ] 未引用「某作品就是这样」这类来源，也未虚构数据或出处。
