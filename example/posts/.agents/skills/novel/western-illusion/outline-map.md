# 创作脉络与大纲地图（novel/western-illusion）

> 把「大纲 + 正文 + 记忆 + `.workshop`」合成一张可核对的旅程地图：分卷走到哪个阶段、地标与势力是否用足、魔法规则是否自洽、哪些设定资产还没进入正文。

## 用途

- 在开新卷、长期停更后恢复、交接或复盘时，快速回答「现在走到哪一段旅程、哪些线还开着、接下来去哪」。
- 把散落在 `outline.md`、正文、人物档案与 `.workshop` 中的信息合成一张结构地图，找出断线、空转与资源闲置。
- 对照旅程阶段、地标锚点与 BOSS 阶梯，检查当前卷是否按计划推进、是否跳过必要阶段。
- 为 `plot-outline.md` 提供输入：指出下一阶段要收的账、可复用的地标与需要补的设定。

## 何时使用

- 写完一卷、准备进入下一个旅程阶段时；
- 写到中段发现「一直在赶路」或「地标用完就丢」时；
- 长期停更后恢复更新，需要先找回上下文时；
- 需要向编辑、合作者或读者说明当前进度与后续规划时；
- 发现人物、地点、魔法规则在正文、记忆与 `.workshop` 之间对不上时。

## 创作进度

> 本技能的第一步是进度回顾：从 `.agents/memories/` 与作品数据源汇总「写到哪、写了多少、还差什么」，再进入具体工作。口径与模板见 `AGENTS.md` §5.4。

### 回顾步骤

1. **读记忆**：先读 `.agents/memories/project.md`、`outline.md`，再按需读 `characters.md`、`world.md`、`continuity.md`、`preferences.md`、`style.md`；目录或文件不存在就跳过，不视为错误。
2. **扫数据**：扫描源目录（`posts/`，不存在则 `src/`）的卷 / 章文件；若存在 `.workshop/`，按 `AGENTS.md` §5.5 读取设定卡、地名、关系与候选条目。
3. **统计**：按下表统计卷 / 章 / 字数、最近更新、伏笔回收、人物与设定条目；所有数值给出「来源」，无法从文件得到时标「未记录」，不估算、不编造。
4. **对齐**：记忆与正文冲突时以正文为准；回顾结论写回 `outline.md`（进度、伏笔）及受影响的类别文件。
5. **输出回顾**：先交付「进度回顾」块，再继续本技能后续的输入与执行步骤。

### 回顾输出

```markdown
## 创作进度回顾
- 当前阶段：<开坑 / 连载中 / 修稿 / 完结>（依据：<...>）
- 上次更新：<日期 / 最新一章>（依据：<...>）

| 项 | 数值 | 来源 |
|---|---|---|
| 卷数 / 章数 | <...> | <...> |
| 已完成章节 | <...> | <...> |
| 总字数 / 章均字数 | <...> | <...> |
| 伏笔 | 埋 <X> / 收 <Y> / 未收 <Z> | <...> |
| 人物 / 地点 / 关系 / 候选 | <...> | <...> |
| `.workshop` 设定卡 | <... / 无> | <...> |

- 当前进度：<写到哪一卷哪一章，主线停在哪>
- 待续事项：<接下来 1–3 件，按优先级>
```

## 输入

| 输入 | 说明 | 缺失时 |
|---|---|---|
| 记忆 | `.agents/memories/` 中的 `outline.md`、`characters.md`、`world.md`、`continuity.md` | 缺失时从正文与 `.workshop` 重建，并标注「推断」 |
| 正文 | `posts/`（不存在则 `src/`）下的卷 / 章文件 | 无正文时按「只有大纲」模式分析，明确说明覆盖范围 |
| 主 SUMMARY.md | 站点元信息与目录结构 | 缺失时只按文件路径与标题分析 |
| `.workshop/`（可选） | 设定卡、地名、关系、候选与图谱 | 不存在时跳过，不视为错误 |
| 分析目标 | 复盘、开新卷、查断线、交接 | 未指定时按「全景复盘 + 下一步建议」执行 |

## 执行步骤

1. **做进度回顾**：按「创作进度」一节输出当前卷 / 章 / 字数与上次更新，作为本次分析的基线。
2. **建旅程地图**：按「受雇 → 启程 → 试炼 → 深入 → 回归 → 余波」标出各阶段所在卷 / 章、进入条件与退出条件。
3. **对齐主线**：沿「世界级目标 → 阶段目标 → 本卷目标 → 当前章目标」逐级检查，断在哪一级就标在哪一级。
4. **抽支线与伏笔**：从章纲和正文抽出势力线、地标线、魔法规则线与伏笔，记录埋点、最近推进、计划回收与状态。
5. **对人物弧线**：对照 `characters.md` 与正文，标出主要人物的起点、当前状态、下一节点与最近出场章。
6. **查地标与行程**：核对每个地标是否至少用两次、是否有中间地带、状态是否随剧情变化。
7. **查势力与 BOSS 阶梯**：对照 `plot-outline.md`，检查每个阶段的势力与 BOSS 是否匹配、奖励是否兑现。
8. **交叉核对 `.workshop`**：按下面的规则把设定卡、地名、关系与候选同正文、记忆对照，列出差异。
9. **找缺口**：缺失阶段、一次性地标、闲置势力、临时新增规则、断线伏笔、长期失踪人物。
10. **给下一步并回写**：输出 1–3 个可执行动作，按优先级排序；把进度与伏笔状态写回 `outline.md`，必要时补 `world.md` / `continuity.md`。

## 脉络识别口径（西幻）

| 线索类型 | 从哪里找 | 判定标准 | 断线信号 |
|---|---|---|---|
| 旅程阶段 | `outline.md` + 正文章节 | 六阶段顺序与功能正确，每段有进入 / 退出条件 | 阶段缺失、顺序颠倒、长期停在试炼 |
| 主线目标 | 长线目标、卷目标、章纲 | 每一级都能回答「为了什么」 | 章目标与卷目标无关 |
| 地标线 | 地标表 + 正文 | 每个地标至少「听说」一次、「抵达」一次，状态会变 | 地标只用一次、缺少中间地带 |
| 魔法规则线 | `world.md` + 正文战斗 | 来源、位阶、代价、冷却、材料、禁忌一致 | 临时新增规则解决当前危机 |
| 势力线 | 势力版图 + 正文 | 每个势力有资源、底线、核心冲突与交换物 | 势力只存在于设定集 |
| BOSS 阶梯 | 阶段 BOSS 表 + 正文章节 | 每阶段 1–2 场，强度与奖励匹配 | BOSS 与阶段不匹配、越阶击杀无代价 |
| 人物弧线 | 人物卡 + 出场章 | 每卷至少一次可追溯的变化 | 长期不出场、变化无事件支撑 |
| 伏笔 | 伏笔表 + 正文 | 埋点、推进、回收齐全 | 只埋不收、回收无铺垫 |

## `.workshop` 交叉核对

> `.workshop/` 是创作资产库，不是事实来源；存在时按下表读取，不存在时整节跳过。

| 文件 | 提供什么 | 怎么用 |
|---|---|---|
| `project.md` | 项目总览、设定、总纲 / 章节清单 | 对照总纲与分析范围；它可能是计划，不等于正文进度 |
| `sheets.md` | 设定卡：人物名、族群、性别、职业、籍贯、关系、备注 | 建人物与关系底账；按 `##` 分卡、`- 字段: 值` 取字段 |
| `places.md` | 地名、族群、备注、结构 | 建地点底账，对照正文地标 |
| `relations.md` | 来源 / 目标 / 关系类型 | 校验人物关系、阵营与图谱连线 |
| `candidates.md` | 名称候选：族群、类型、性别、稀有度、字数、来源、收藏 | 找尚未使用的命名资产 |
| `graph.md` | 节点数 / 连线数与快照 | 快速核对数量、孤儿节点与孤立设定 |
| `preferences.md` | 生成规则与候选库筛选条件（JSON） | 只作生成偏好，不作情节事实 |
| `sheets.ini` | 人物 / 候选速查（INI） | 与 `sheets.md` 交叉核对，冲突以 `sheets.md` 为准 |
| `overview.md` | 可为空 | 空文件直接跳过 |

**冲突优先级**：正文 > 用户新指令 > `.agents/memories/` > `.workshop/`。冲突处必须标注「正文与卡片不一致」并给出处理建议，不能静默采信任何一方。

AI **只读** `.workshop/`，不修改这些文件；核对结论写回 `.agents/memories/`（`outline.md`、`characters.md`、`world.md`、`continuity.md`）。

## 质量检查清单

- [ ] 进度数据都有来源，未知项标了「未记录」，没有估算冒充统计；
- [ ] 六阶段顺序与功能正确，缺失阶段或跳过阶段已标出；
- [ ] 主线能从世界级目标一路追到当前章，断点位置明确；
- [ ] 每个地标至少用过两次，且有中间地带与状态变化；
- [ ] 魔法规则在正文中前后一致，临时突破已标为风险；
- [ ] 势力与阶段 BOSS 匹配，奖励与代价都有兑现；
- [ ] 每条支线与伏笔都记录了埋点、最近推进与回收状态；
- [ ] `.workshop` 存在时已完成交叉核对，不存在时没有编造卡片内容；
- [ ] 冲突按「正文 > 用户指令 > 记忆 > `.workshop`」处理并标注；
- [ ] 「下一步」不超过 3 件，且按优先级排序。
