# 西幻战斗与探索场景张力评分（novel/western-illusion）

> 分别给战斗场景与探索场景打分，定位「像流水账」的段落，并给出符合世界规则的加压手段。

## 用途

- 量化西幻的两种核心场景——**战斗**与**探索**——的张力，找出读起来平、赶、重复的段落。
- 判断某个战斗场景是否兑现了前面铺垫的规则与伏笔，而不是临时加戏。
- 判断某段探索是否只是赶路，缺少可获得的东西与未知威胁。
- 在改稿前给出可执行的处置（加压、合并、删、换视角、调顺序），而不是笼统的「再打磨」。

## 何时使用

- 写完一章或一卷后自检节奏；
- 读者反馈「战斗像报技能」「一直在赶路」时；
- 调整卷内顺序、压缩篇幅、合并遗迹前；
- 战斗与探索比例失衡（连续遭遇战或连续过渡）时。

## 输入

| 输入 | 说明 | 缺失时 |
|---|---|---|
| 场景文本 | 连续的一段战斗或探索 | 必须有 |
| 场景目标 | 该场景在卷内的作用（拿线索 / 争时间 / 换通行 / 立威胁） | 从大纲或 `plot-outline.md` 推断 |
| 世界规则基线 | magic system 六要素、位阶标尺、地标与行程 | 缺失时先做 `premise-generator.md`，或从正文抽取并标注「推断」 |
| 队伍状态 | 位阶、伤势、补给、材料、声望 | 从正文抽取；缺失项标「待补」 |
| 类型取向 | High fantasy / Sword and sorcery / Hard fantasy / 低魔 | 按故事核推断，并说明依据 |

## 执行步骤

1. **切分场景**：按「视角人物 + 时间地点连续」切分，标出场景序号、类型（战斗 / 探索 / 过渡）与篇幅。
2. **分类打分**：战斗用「战斗评分维度」，探索用「探索评分维度」，过渡场景只需判断是否必要。
3. **画曲线**：把分数连成曲线，标出平台期（连续两场分数接近且偏低）与尖峰。
4. **查规则兑现**：战斗里的关键结果能否由已写规则推出；若靠临时设定解决，直接记为「规则失守」。
5. **归因**：对低分场景逐项归因——无目标、无阻碍、无代价、无变化、线索重复、地形无作用、撤退无成本。
6. **给处置动作**：每个低分场景给一个具体动作（加压 / 合并 / 删 / 换视角 / 让地标状态变化 / 后置）。
7. **给加压清单**：给出 3–5 条可直接落地的加压手段，每条注明用在哪个场景、改变哪个变量。

## 战斗评分维度

| 维度 | 0 分 | 10 分 |
|---|---|---|
| 规则可推演 | 结果全靠临场发挥 | 读者能依据已写规则预判胜负与代价 |
| 代价可见 | 赢了没有损失 | 每场胜利消耗明确的资源、伤势、材料或声望 |
| 位置与地形 | 空地对轰 | 地形、视野、掩体、退路真实影响打法 |
| 资源消耗 | 药水与法术位无限 | 补给、材料、法力/体力按前文账目消耗 |
| 撤退选项 | 只能赢或死 | 撤退有成本但不被封死，逼出选择 |
| 结果变化 | 打完和没打一样 | 至少一个关键变量被永久改变（人员、通道、声望、情报） |
| 观众效应 | 无人知晓 | 有人在看、有人记着，胜负带来后续反应 |

## 探索评分维度

| 维度 | 0 分 | 10 分 |
|---|---|---|
| 线索密度 | 走完全程零收获 | 每段探索至少带回一条可用的线索或物件 |
| 未知威胁 | 全程安全 | 有可感知但未现形的威胁，压力随时间升高 |
| 环境互动 | 风景描写堆砌 | 环境提供解法或制造限制（机关、地形、生物、天气） |
| 补给与时间 | 不计消耗 | 补给、火把、天数成为真实约束 |
| 发现回报 | 发现没有用途 | 发现被后续用上，或被势力争夺 |
| 空间记忆 | 记不住走过哪 | 地标可被复述，回程/引用时不迷路 |

## 曲线判读

| 曲线形态 | 含义 | 处理 |
|---|---|---|
| 持续上升 | 正常推进 | 保持 |
| 高开低走 | 开篇抓人，中段泄气 | 合并前两场，或把高开的信息后置 |
| 平台期 | 连续多场分数相近且偏低 | 插入转折、让地标状态变化，或合并压缩 |
| 锯齿 | 高低交替过于频繁 | 保留 1–2 个低谷作为呼吸，其余拉平 |
| 结尾平 | 最后一场无变化 | 收束场必须交代后果、回报归属与新常态 |
| 尖峰孤立 | 一场极高、前后都低 | 把尖峰的代价分摊到前后场景，避免「一章爽完就冷」 |

## 加压手段

| 手段 | 做法 | 适合 |
|---|---|---|
| 封退路 | 让撤退成本高到不能接受 | 逼出正面选择 |
| 断补给 | 材料、药水、火把、马匹不够用 | 让资源账目立刻生效 |
| 加时限 | 给任务加截止时间（潮汐、增援、契约到期） | 推动决策 |
| 让规则反噬 | 施法的代价在此刻结算 | 兑现 magic system 的硬边界 |
| 地标变化 | 城镇被封锁、遗迹塌方、道路被占 | 让世界不静止 |
| 换视角 | 从对手 / 受害者 / 旁观者写同一事件 | 增加张力层次 |
| 提前暴露威胁 | 让后文的威胁先露一角 | 制造回看价值 |
| 削选项 | 拿掉最省事的那条路 | 逼出主角的主动选择 |

## 质量检查清单

- [ ] 场景切分基于视角与时空，不是按字数硬切，且区分了战斗 / 探索 / 过渡；
- [ ] 每个维度都有正文依据，不是整体印象分；
- [ ] 关键战斗结果都能由已写规则推出，临时新增设定被单独列出；
- [ ] 低分场景给了**具体**处置动作，而不是「再打磨一下」；
- [ ] 曲线图与分数表一致，尖峰孤立与平台期都被指出；
- [ ] 加压清单里的每一条都能落到某个场景，并写明改变哪个变量；
- [ ] 没有用分数否定「安静场景」的价值（呼吸场景可以是低分但必要）；
- [ ] 未虚构设定出处、销量、榜单或「某作品就是这样写」一类来源。
