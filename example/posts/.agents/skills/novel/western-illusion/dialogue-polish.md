# 西幻对白与称谓打磨（novel/western-illusion）

> 打磨西幻对白：按势力与阶层的敬称差异、种族口吻差异、宫廷 / 野外 / 战场三种语域去除现代腔与说明设定式台词，并写出潜台词与信息差。

## 用途

- 修掉「说明书式对白」「现代商务腔」「两个信息交换器」。
- 让称谓承载关系与立场：谁被称作爵士，谁被称作「术士」。
- 让不同种族、阶层、势力的人说话方式可辨。
- 用潜台词与信息差制造张力，而不是靠抬高音量。

## 何时使用

- 初稿完成后精修对白时；
- 读起来像现代职场对话、像作者在替角色讲设定时；
- 需要为某场对话增加压迫感、恭敬感或喜剧感时；
- 多人场景里读者分不清谁在说话时。

## 创作进度

> 本技能的第一步是进度回顾：从 `.agents/memories/` 与作品数据源汇总「写到哪、写了多少、还差什么」，再进入具体工作。口径与模板见 `AGENTS.md` §5.4。

### 回顾步骤

1. **读记忆**：先读 `.agents/memories/project.md`、`outline.md`，再按需读 `characters.md`、`world.md`、`continuity.md`、`preferences.md`、`style.md`；目录或文件不存在就跳过，不视为错误。
2. **扫数据**：扫描源目录（`posts/`，不存在则 `src/`）的卷 / 章文件；若存在 `.workshop/`，按 `AGENTS.md` §5.5 读取设定卡、地名、关系与候选条目。
3. **统计**：按下表统计卷 / 章 / 字数、最近更新、伏笔回收、人物与设定条目；所有数值给出「来源」，无法从文件得到时标「未记录」，不估算、不编造。
4. **对齐**：记忆与正文冲突时以正文为准；回顾结论写回 `outline.md`（进度、伏笔）及受影响的类别文件。
5. **输出回顾**：先交付「进度回顾」块，再继续本技能后续的输入与执行步骤。

## 输入

| 输入 | 说明 | 缺失时 |
|---|---|---|
| 对白片段 | 原文段落 | 必须有 |
| 场景元信息 | 地点、在场者、权力关系、时段 | 从正文抽取；抽取不到时向用户确认 |
| 人物档案 | 各人目标、秘密、语言特征、称谓习惯 | 缺失时先做 `character-bible.md` |
| 势力归属 | 在场各人所属势力与职衔 | 从正文抽取并标注「推断」 |
| 语域要求 | 这次对话处于宫廷 / 野外 / 战场 | 未指定时按场景地点推断并说明 |

## 执行步骤

1. **标注意图**：给每句对白写「说话人此刻想从对方那里得到什么」。
2. **定语域**：按地点与场合选定语域（宫廷 / 野外 / 战场），确定句长、用词与省略程度。
3. **核称谓**：核对每处称呼在**双方所属势力**中是否成立；同一个人的称呼在敌对势力里应不同。
4. **找直白处**：凡是直接说出真相、感受、请求的句子都是候选。
5. **改写为行动**：把直白句换成「做什么 + 说什么（或不说）」。
6. **去现代腔**：删掉现代商务 / 技术 / 流程词，换成该世界该身份真会用的词。
7. **删设定倾倒**：凡是「为让读者明白世界观」而存在的台词，改为可观察的行动、物件或旁白。
8. **补潜台词**：给重要对白写一句「没说出口的真实意思」。
9. **查信息差**：确认谁知道什么、谁不知道；冲突应来自信息差而非音量。
10. **分声线**：遮住人名，能否认出说话人。
11. **朗读**：念一遍，标出拗口、绕口、念不顺的句子。

**使用规则**

- 上下级之间用敬称，同侪之间用绰号或职业称；陌生人之间先问名分再说话；
- 称谓本身要**可变**：升职、失势、入教、叛出、被除名都会改变别人怎么叫你；称谓变化本身就是剧情；
- 敌对势力对敌方人物用**贬称**（绰号、族称、罪名），且各势力贬法不同；
- 不确定时宁可写「他用了对方的全名与职衔」，也不要凭空发明一个敬称体系。

## 种族口吻差异（通用倾向）

| 种族倾向 | 说话特征（通用） | 常见误用 | 正确用法 |
|---------|----------------|---------|---------|
| 精灵 | 长句、完整句式、关注时间尺度与礼节 | 写成「冷血旁白机器」 | 给一段极其礼貌但暗藏拒绝的对话 |
| 矮人 | 直接、具体、以工艺与实物衡量事物 | 写成「只谈喝酒和锻造」 | 让其直说不体面的话，但对方会当真 |
| 半身人 | 日常、口语化、绕远路谈实际 | 写成只讲食物的喜剧角色 | 用琐碎与自嘲掩盖真正目的 |
| 人类 | 变数最大、政治敏感度高 | 写成「标准主角族」 | 用身份与场合决定他的语域 |
| 巨龙裔 | 古语、傲慢、对契约与称谓极敏感 | 写成会吼叫的怪物 | 用称谓与礼仪体现傲慢，而非嗓门 |

> 这些是**倾向**不是定论：同一个种族内部必须有说话不同的人，否则种族会变成单一音色。

## 三种语域对照

| 维度 | 宫廷 | 野外 | 战场 |
|------|------|------|------|
| 句长 | 长、完整、留余地 | 短、直给 | 极短，祈使与省略 |
| 称呼 | 敬称 + 职衔 + 谦称 | 名字或绰号 | 代号与位置（左边、楼上、掩护） |
| 内容 | 暗示、迂回、试探 | 事实、方位、天气、补给 | 指令、确认、报数 |
| 禁忌 | 直说反对、提钱、提婚 | 谈魔法、谈神、谈贵族 | 分心、喊全名、解释长句 |
| 典型错误 | 省略敬称、说话像合同 | 忽然掉书袋 | 边打边做长篇解释 |

## 现代腔词表（需要替换）

| 现代腔 | 问题 | 替换方向 |
|--------|------|---------|
| 「没问题 / OK / 收到」 | 二十世纪口语缩写 | 「知道了」「听你的」「我明白」 |
| 「我需要一份方案 / 资源 / 预算」 | 现代商务流程词 | 具体物品与数目：粮、钱、箭、药、许可 |
| 「信息 / 数据 / 效率 / 方案」 | 现代管理词 | 「消息 / 风声 / 门路 / 打算」 |
| 「你是专业的吗 / 我们得评估一下」 | 现代职场话术 | 对方凭身份说话：学徒、匠人、军官 |
| 「我们团队 / 项目」 | 现代组织词 | 「我们一伙」「这一行」「这桩差事」 |
| 「别开玩笑了 / 认真的吗」 | 现代网络语 | 「休得胡言」「你当我是傻子」或直接沉默 |

## 说明设定式台词

**特征**：人物停下来向对方解释对方本应知道的世界规则，纯粹为了让读者明白设定。

**改写手法**

| 原句（说明设定式） | 改写方向 |
|--------------------|---------|
| 「你要知道，法师施法需要先画符，因为魔力只能通过媒介传导。」 | 让他**画**，或者让施法失败一次，规则自然显形 |
| 「精灵寿命很长，所以他们的政治周期比人类慢。」 | 让精灵说「你们这一代人，还没经历过上一次霜年」 |
| 「教会掌控着城市的粮仓，这是他们一直以来的传统。」 | 让粮食从教会门口运走，让守卫拦下队伍 |
| 「这个遗迹在上古战争中就被封了。」 | 让封条还在、锁孔被撬过、或有人不肯进 |

> 判据：删掉这句台词，读者是否仍能从场景里得到这条信息？能，就该删。

## 潜台词与信息差

| 机制 | 做法 | 检验 |
|------|------|------|
| 潜台词 | 说 A，实际要 B | 遮住台词，问「他想干什么」，答案应不与字面重合 |
| 信息差 | A 知道 B 不知道 | 读者知道其中一方知道，就能产生预期焦虑 |
| 半真话 | 说一半，剩下靠上下文 | 对方追问时应有具体回避，而不是含糊带过 |
| 权力落差 | 下位者不敢直说 | 用省略、铺垫、请教包装真实诉求 |
| 试探性提问 | 问 A 来探 B | 回答本身要与问题错开 |

## 对白检查表

| 检查 | 通过标准 |
|------|---------|
| 意图明确 | 每句重要对白背后都有可写的意图 |
| 语域统一 | 整场对话处在同一语域，不随场景类型漂移 |
| 称谓成立 | 每处称呼在双方势力关系中说得通 |
| 声线可辨 | 遮住人名能认出说话人（至少在同一势力内可辨） |
| 无现代腔 | 无现代商务 / 技术 / 网络词 |
| 无设定倾倒 | 没有纯为读者解释设定的台词 |
| 有动作与沉默 | 对白中有可观察行为、停顿或感官细节 |
| 信息差存在 | 至少一方在隐瞒，隐瞒有代价 |

## 质量检查清单

- [ ] 每句重要对白都写出了潜台词，且与字面不重合；
- [ ] 场景语域前后一致，没有在同一场戏里从宫廷切到现代口吻；
- [ ] 每处称谓在双方势力的关系中成立，贬称与敬称有区分；
- [ ] 已删掉或改写纯为读者解释设定的台词；
- [ ] 没有现代商务 / 技术 / 网络用语；
- [ ] 每个说话人的声音可辨认（同势力内至少可区分）；
- [ ] 种族口吻写成倾向而非定论，同族内存在差异；
- [ ] 改写没有改变剧情信息量、人物关系与力量差。
