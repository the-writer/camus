# 西幻人物与阵营档案（novel/western-illusion）

> 建立西幻人物与势力的可持续档案：队伍分工、种族与信仰、职业行事逻辑、动机链、称谓与语域。

## 用途

- 让冒险者队伍成为一个**互相补位**的整体，而不是技能拼盘。
- 让职业、种族、信仰对人物行为产生可观察的影响。
- 用利益与底线描述阵营，替代「好人 / 坏人」标签。
- 排查人物动机断裂与前后不一致（称谓、口吻、能力边界）。

## 何时使用

- 开写前组建队伍、确定人物关系时；
- 写到「他这么做说不通」时；
- 队伍加人、减人或合并没有功能的角色时；
- 校对时检查人物设定与正文是否冲突。

## 输入

| 输入 | 说明 | 缺失时 |
|---|---|---|
| 故事核 / 一句话梗概 | 人物所处的核心冲突 | 必须有 |
| 世界设定基线 | magic system、种族、势力版图 | 缺失时先做 `premise-generator.md`，或从正文抽取并标注「推断」 |
| 已有的人物线索 | 正文出现过的名字、称呼、关系 | 扫描正文抽取 |
| 队伍形态 | 单人冒险 / 固定队伍 / 临时拼伙 | 未指定时按「固定队伍」假设并说明 |
| 篇幅 | 决定配角数量与档案深度 | 未指定时按长篇假设并说明 |

## 执行步骤

> 动机链、关系网写法、语言 / 称谓维度、工具人检查与通用一致性表见 `.agents/shared/novel-character.md`；本技能只写队伍、种族、信仰与职业专项。

1. **列人物**：从正文抽取所有有名有姓的人物与代称，标注出场次数。
2. **分配叙事功能**：主角 / 对手 / 盟友 / 导师 / 镜子 / 门槛。
3. **定队伍分工**：为每人指定**队伍职能**（侦察、攻坚、治疗、支援、谈判、护送），并标出缺口。
4. **落位阶**：把每人放进 magic system 的位阶标尺，标注「读者已知 / 读者未知」。
5. **写种族与信仰影响**：他因为身为某族 / 信奉某神而**具体地**能做什么、不能做什么、忌讳什么。
6. **写职业行事逻辑**：按职业惯例给出他的默认解法，再写他何时**违背**惯例（这一处就是人物性）。
7. **填动机链**：按 `.agents/shared/novel-character.md` §1 的模板逐项填写；缺项写「待补」。
8. **写关系网**：按 `.agents/shared/novel-character.md` §2 的功能性写法，不用「朋友」「敌人」空标签。
9. **定称谓与语域**：他如何称呼他人、他人如何称呼他、在不同势力场合的敬称差异。
10. **一致性检查**：对照正文找行为冲突，输出问题清单与处置方式。

## 队伍分工与位阶

| 职能 | 通用职责 | 常见职业 | 队伍里的稀缺性 |
|------|---------|---------|---------------|
| 侦察 | 探路、辨踪、预警 | 游侠 / 盗贼 | 高：失败会拖垮全队 |
| 攻坚 | 正面承压、破门 | 战士 / 圣武士 | 中 |
| 施法输出 | 范围打击、改变地形 | 法师 / 术士 | 高：受材料与准备时间限制 |
| 治疗支援 | 续航、解除异常、祝福 | 牧师 / 德鲁伊 | 高：常是唯一解法 |
| 交涉 | 与势力谈判、读契约 | 学者 / 贵族出身者 / 盗贼 | 高：野外无用、城内关键 |
| 后勤保障 | 补给、马匹、修装 | 佣兵老兵 / 半精灵 | 低：没人愿当，但缺了会崩 |

> 「常见职业」只是职能的通用搭配，不是本世界职业表；职能缺口由故事需求决定，不由职业数量决定。

## 职业行事逻辑

| 职业 | 默认解法（通用倾向） | 惯用手段 | 性格代价 | 例外时刻 |
|------|-------------------|---------|---------|---------|
| 战士 | 正面对决，用体力与装备换空间 | 找位置、等时机、不追击 | 直率、易被激 | 违背直觉时必有理由 |
| 游侠 | 侦察与牵制，用距离换信息 | 探路、示警、标记退路 | 耐心、话少、护短 | 放下距离保护同伴时 |
| 法师 | 用规则解决问题，不近身 | 准备、材料、预案 | 冷静、刻薄、依赖预案 | 预案失效时 |
| 牧师 | 用信仰授权的手段救人与驱散 | 治疗、驱邪、鼓舞 | 坚定、有禁忌 | 信仰被质疑或失效时 |
| 盗贼 | 用信息与位置解决问题 | 潜入、销赃、找门路 | 务实、多疑、留后手 | 交出后路时 |
| 德鲁伊 | 与地界共生，按自然法则取舍 | 变形、沟通野兽、察觉异常 | 疏离、慢热、有戒律 | 必须介入人间事务时 |

> 上表是**倾向**不是定律：写具体人物时必须给出他偏离这一倾向的经历与代价，否则人物会滑成职业模板。

## 种族与信仰的影响面

| 影响面 | 要回答的问题 |
|--------|------------|
| 生理与寿命 | 他的体力、恢复速度、寿命预期如何改变他的选择 |
| 聚落与地理 | 他来自哪种聚落，为什么离开，路上会找谁 |
| 偏见 | 他对哪些人有先入之见，这种偏见在哪个场景会惹祸 |
| 禁忌 | 哪些话、哪些食物、哪些仪式会让他当场翻脸 |
| 信仰 | 他信的神（或不信）提供什么禁令、安慰、身份标签 |
| 内部矛盾 | 他与本族哪一派看法不同 |

> 种族提供处境与偏见，不提供道德结论；把某个种族整体写成正义或邪恶是常见漏洞。

## 称谓与语域特征

| 场合 | 称呼方向 | 语域特征 |
|------|---------|---------|
| 宫廷 | 对上级用敬称与尊号，异议用迂回表达 | 长句、少直呼其名、先给身份再给诉求 |
| 神殿 / 学院 | 以职务、职衔、行会身份相称 | 精确、书面、避讳俗语 |
| 商会 / 公会 | 伙伴式称呼，交易时极务实 | 短句、数字与行话、称呼随利益变 |
| 佣兵团 | 绰号、军衔式称呼、命令式短句 | 粗粝、祈使、多否定句 |
| 野外 | 只用名字或绰号 | 极简、方位与距离优先 |

> 同一人物在不同势力之间被称呼的方式不同，本身就是信息：能写进正文当伏笔。

## 一致性检查表

| 检查 | 通过标准 |
|------|---------|
| 分工互补 | 每人有不可替代的队伍职能，且与他人不重叠 |
| 位阶一致 | 人物展现实力不超出其位阶，越阶处有铺垫与代价 |
| 职业逻辑可解释 | 每个关键行为能追溯到职业惯例 + 一次例外 |
| 种族影响具体 | 至少有一处行为直接由种族或信仰处境导致 |
| 阵营有底线 | 每个阵营人物都写得出自己不肯做的底线 |
| 动机链完整 | 外在目标与内在需求不同，且秘密一旦暴露有真实损失 |
| 称谓可核查 | 关系变化时称谓同步变化，无人前后被叫错 |

## 质量检查清单

- [ ] 队伍里每人有明确且不重叠的职能，缺口已标出；
- [ ] 每个人的位阶有依据，越阶处写了铺垫与代价；
- [ ] 职业行事逻辑写到了「默认解法 + 一次例外」，不是只写职业标签；
- [ ] 每个种族都写了内部矛盾，没有被当成善恶阵营；
- [ ] 每个阵营都有资源、底线与核心冲突；
- [ ] 外在目标与内在需求**不同**，秘密一旦暴露会造成真实损失；
- [ ] 称谓随关系与场合变化，且与正文一致；
- [ ] 未凭空新增正文中不存在的人物或背景。
