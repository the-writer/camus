# 网文对白与爽点台词打磨（novel/online）

> 把对白改成网文读者看得快的形态：短句、口语、去口水话，同时保住打脸与反杀的潜台词和力度。

## 用途

- 修掉「两个信息交换器」式对白，让每句都带态度。
- 写出能被截图传播的爽点台词：短、断、有落差。
- 在群像对话里让读者不看人名也能分清谁在说话。
- 压缩口水话与作者腔旁白，提升网文移动端阅读的顺畅度。

## 何时使用

- 初稿完成后逐章精修对白；
- 读者反馈「读着像剧本」「台词太长」时；
- 打脸 / 反杀场景写完但「不够响」时；
- 群像会议 / 对峙戏里人物声音混作一团时。

## 创作进度

> 本技能的第一步是进度回顾：从 `.agents/memories/` 与作品数据源汇总「写到哪、写了多少、还差什么」，再进入具体工作。口径与模板见 `AGENTS.md` §5.4。

### 回顾步骤

1. **读记忆**：先读 `.agents/memories/project.md`、`outline.md`，再按需读 `characters.md`、`world.md`、`continuity.md`、`preferences.md`、`style.md`；目录或文件不存在就跳过，不视为错误。
2. **扫数据**：扫描源目录（`posts/`，不存在则 `src/`）的卷 / 章文件；若存在 `.workshop/`，按 `AGENTS.md` §5.5 读取设定卡、地名、关系与候选条目。
3. **统计**：按下表统计卷 / 章 / 字数、最近更新、伏笔回收、人物与设定条目；所有数值给出「来源」，无法从文件得到时标「未记录」，不估算、不编造。
4. **对齐**：记忆与正文冲突时以正文为准；回顾结论写回 `outline.md`（进度、伏笔）及受影响的类别文件。
5. **输出回顾**：先交付「进度回顾」块，再继续本技能后续的输入与执行步骤。

- 上次更新：<日期 / 最新一章>（依据：<...>）

## 输入

| 输入 | 说明 | 缺失时 |
|---|---|---|
| 对白片段 | 原文段落 | 必须有 |
| 场景元信息 | 地点、在场者、权力关系、谁占上风 | 从正文抽取；抽取不到则向用户确认 |
| 人物档案与声线 | 各人身份、地位、说话习惯 | 缺失时先跑 `novel/online/character-bible.md`，或按本场景临时推一份并标注「推断」 |
| 本章目标与爽点 | 这段要完成什么、爽点类型 | 从章纲推断；无章纲则标「待补」 |
| 题材与基调 | 冷硬、诙谐、热血、日常 | 向用户确认；未确认时按「口语化、略热血」处理并说明 |

## 执行步骤

1. **标注意图**：给每句对白写「说话人此刻想从对方那里拿到什么」。
2. **切长短句**：把超过一口气读完的句子拆成 1–3 句；删掉从句堆叠。
3. **去口水话**：删「嗯」「那个」「就是说」等填充词（保留有性格的口头禅）。
4. **还原口语**：把书面连接词（诸如「然而」「因此」「并且」）换成说话人真会用的说法。
5. **调爽点节奏**：打脸与反杀台词按「短句—停顿—更狠的一句」排版，重要句子单独成段。
6. **分身份语气**：给在场每人定一条语气规则（用词、称呼、句长、是否敬语），逐句核对。
7. **补潜台词**：给重要对白写一句「没说出口的真实意思」，确认力度来源。
8. **查动作**：重要台词最好带一个可观察的动作或沉默，避免纯说话。
9. **朗读检查**：念一遍，标出拗口、绕口、像作者在说话（作者腔）的句子。
10. **自检**：跑「网文对白自检表」。

## 网文对白特征表

| 特征 | 表现 | 反例 |
|------|------|------|
| 短句 | 单句大多在一口气内读完；长信息拆成两三句 | 「那青年闻言，神色微变，旋即便欲开口反驳道……」 |
| 口语 | 用「你」「我」「咱」「这玩意儿」，少用书面语连接 | 「然而」「与此同时」「因而」 |
| 短段落 | 每次发言单独成段，一段不超过 3–5 行 | 整段都是引号 |
| 有态度 | 每句带情绪或立场，不做中转站 | 「事情就是这样。」「我知道了。」 |
| 留白 | 关键信息用动作、沉默或岔开承载 | 直说「我很担心你」 |

## 口水话清单

| 类型 | 例子 | 处理 |
|------|------|------|
| 语气填充 | 嗯、啊、呃、这个、那个 | 直接删；需要迟疑时用动作代替（「他张了张嘴」） |
| 承接填充 | 对啊、是啊、你说得对、没错 | 删掉不影响理解就删 |
| 复述填充 | 「你是说……」「也就是说……」 | 只有角色确实在确认信息时才留 |
| 客套填充 | 「久仰久仰」「不敢当」「哪里哪里」 | 只在有身份含义的场合留一句 |
| 作者腔 | 「他心中暗道」「她不禁想到」 | 改为叙述短句或直接删 |
| 重复强调 | 同一信息连说两遍 | 保留信息最强的一次 |

## 爽点台词写法

| 场景 | 结构 | 示范骨架 |
|------|------|----------|
| 打脸 | 对方先定性 → 主角一句短句 → 事实补刀 | 「你算什么？」<br>「我算什么不重要。」<br><事实落地> |
| 反杀 | 对方以为赢了 → 主角揭示早有准备 → 代价落到对方 | 「这局，你输了。」<br>「不，是你先动的手。」 |
| 升级 | 报境界 → 对方不信 → 用结果说话 | 「我现在是什么境？」<br>对方沉默。<br>「那就对了。」 |
| 扮猪吃虎 | 被轻视 → 不辩解 → 事后兑现 | 「你配吗？」<br>（不接话，只做事）<br>「刚才那句话，再说一遍？」 |
| 身份揭晓 | 质疑 → 一个关键称谓 / 凭证 → 对方失态 | 「你到底是谁？」<br>「你该叫我一声前辈。」 |
| 护短 | 对方动手 → 有人拦住 → 一句定性 | 「动他？问过我了没有。」 |
| 复仇 | 旧账被提起 → 主角复述旧账 → 清算 | 「三年前那笔账，我今天来收。」 |

> 力度来自「落差 + 短句 + 事实」，不来自形容词堆叠。

## 群像身份语气对照表

| 身份 | 句长 | 称呼 | 用词倾向 | 忌讳 |
|------|------|------|----------|------|
| 主角 | 短、稳 | 直呼其名或直说事 | 少修饰词 | 不说教、不总结大道理 |
| 长辈 / 导师 | 中长 | 带敬称或旧称 | 抽象、留白 | 不当场点破一切 |
| 同辈 / 主角团 | 短促 | 昵称、外号 | 玩笑、俗语 | 不互相抬轿 |
| 对手 | 短、硬 | 按地位称呼 | 命令、断言 | 不长篇大论 |
| 反派 | 稳、慢 | 称名带敬 | 文雅、施压 | 不自曝计划 |
| 路人 / 工具角色 | 极短 | 泛称 | 单句 | 不承担解释设定的任务 |

## 改写示例

| 原句 | 问题 | 改写 |
|------|------|------|
| 「你不过是个外门弟子罢了，怎么可能赢得了我？」 | 长定语堆叠 + 语义拖沓 | 「外门弟子？」<br>「赢你，还不用。」 |
| 「我劝你最好现在就放弃抵抗，否则后果自负。」 | 书面腔 + 空洞威胁 | 「现在收手。」<br>「晚了。」 |
| 「你难道不知道我父亲是谁吗？」 | 直白索取信息 | 「你先报个名字。」<br>「我怕你不敢听。」 |

## 反面清单

| 反面写法 | 危害 | 替代 |
|----------|------|------|
| 长定语堆叠 | 移动端阅读吃力 | 拆成短句，先给动作再给修饰 |
| 生僻词 / 硬拗辞藻 | 网文读者读不动，节奏断掉 | 用日常词替换 |
| 作者旁白总结 | 「他意识到自己已经无敌了」式总结削弱画面 | 用动作与结果让读者自己得出结论 |
| 主角全程被动、靠巧合推进 | 爽点变成别人的功劳 | 让主角主动选择并承担代价 |
| 配角只用来提问 | 对白沦为信息索取工具 | 让配角带自己的诉求和隐瞒 |
| 敌人降智只为衬托主角 | 打脸失去分量 | 给对手合理的判断依据 |

## 网文对白自检表

| 检查 | 通过标准 |
|---|---|
| 读得下去 | 每句一口气能读完，长句已拆 |
| 无口水话 | 删掉语气填充后语义不丢 |
| 有态度 | 每句背后有可写的意图，没有纯应答 |
| 声线可辨 | 遮住人名能认出说话人 |
| 爽点台词够响 | 打脸 / 反杀处有「短句 + 落差 + 事实」 |
| 潜台词在场 | 重要对白都能补出「没说出口的真实意思」 |
| 动作伴随 | 关键台词伴随动作或沉默，不是纯说话 |
| 无作者腔 | 没有作者的话从角色嘴里说出来 |

## 质量检查清单

- [ ] 长句已拆成短句，读起来是一口气能读完的节奏；
- [ ] 口水话已删干净，有性格的口头禅保留并标注；
- [ ] 每句重要对白都写出了说话人意图与潜台词；
- [ ] 打脸 / 反杀处有短句、落差与事实支撑，不是靠形容词喊情绪；
- [ ] 群像对话中每个人的称呼与句长能区分身份；
- [ ] 关键台词伴随动作或沉默，没有纯说话段落；
- [ ] 反面清单中的问题（长定语、生僻词、作者旁白、主角被动、对手降智）逐项排查过；
- [ ] 改写没有改变剧情信息量、人物关系与伏笔位置。
