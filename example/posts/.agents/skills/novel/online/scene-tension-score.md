# 网文章节节奏与爽点评分（novel/online）

> 逐章打分找出塌陷章：爽点密度、进展感、钩子强度、节奏拖沓、信息重复，并给出可直接插进正文的加压手段。

## 用途

- 连载期自检：写完一章就能打分，判断这章值不值得发。
- 定位塌陷章：连续无进展、只有赶路与解释的段落。
- 检查爽点频率：太稀读者流失，太密读者疲劳。
- 给具体加压动作，而不是「再充实一点」这种空话。

## 何时使用

- 每写完 3–5 章做一次小结，或写完一卷整体体检；
- 读者反馈「追不动」「后面没意思」时；
- 准备切卷、压缩长段、补写爽点前；
- 统计自己的「章末钩子」有没有断档。

## 创作进度

> 本技能的第一步是进度回顾：下文用 `<source>` 指源目录（`src/` 或 `posts/`）；从 `<source>/.agents/memories/` 与作品数据源汇总「写到哪、写了多少、还差什么」，再进入具体工作。口径与模板见 `AGENTS.md` §5.4。

### 回顾步骤

1. **读记忆**：先读 `<source>/.agents/memories/project.md`、`outline.md`，再按需读 `characters.md`、`world.md`、`continuity.md`、`preferences.md`、`style.md`；目录或文件不存在就跳过，不视为错误。
2. **扫数据**：扫描源目录（`posts/`，不存在则 `src/`）的卷 / 章文件；若存在 `.workshop/`，按 `AGENTS.md` §5.5 读取设定卡、地名、关系与候选条目。
3. **统计**：按下表统计卷 / 章 / 字数、最近更新、伏笔回收、人物与设定条目；所有数值给出「来源」，无法从文件得到时标「未记录」，不估算、不编造。
4. **对齐**：记忆与正文冲突时以正文为准；回顾结论写回 `outline.md`（进度、伏笔）及受影响的类别文件。
5. **输出回顾**：先交付「进度回顾」块，再继续本技能后续的输入与执行步骤。

```markdown

- 上次更新：<日期 / 最新一章>（依据：<...>）

| 项 | 数值 | 来源 |
|---|---|---|
| 卷数 / 章数 | <...> | <...> |
| 已完成章节 | <...> | <...> |
| 总字数 / 章均字数 | <...> | <...> |
| 伏笔 | 埋 <X> / 收 <Y> / 未收 <Z> | <...> |
```

## 输入

| 输入 | 说明 | 缺失时 |
|---|---|---|
| 章节正文 | 连续若干章（建议至少 5 章，才能看出频率） | 必须有 |
| 章纲 / 卷目标 | 每章该完成什么 | 缺失时从正文反推并标注「推断」 |
| 爽点承诺表 | 读者被承诺了什么 | 缺失时按「打脸 / 升级 / 扮猪吃虎 / 身份揭晓 / 护短 / 复仇」六类现列草稿并说明 |
| 节奏基线 | 作者自定的更新频率与期望强度 | 按「每 3–5 章一个小高潮、每卷末一个大高潮」的常见量级假设，并标注「参考值，非硬性规定」 |

## 执行步骤

1. **切分并编号**：按章为单位；若某章内含多场戏，标出「章内小高潮」。
2. **逐章打分**：按下面 5 个维度打 0–10 分，每项写一句依据。
3. **标爽点位置**：在每章标出爽点类型与强度（弱 / 中 / 强），并注明是即时爽点还是伏笔回报。
4. **画节奏曲线**：把「爽点强度 + 进展感」连成曲线，标出平台期与尖峰。
5. **查频率**：统计小高潮间隔是否超过 5 章、卷末是否有大高潮、是否出现连着 3 章以上的高强度。
6. **归因塌陷**：对低分章区分主因——无进展 / 节奏拖沓 / 信息重复 / 钩子缺失 / 爽点缺席。
7. **给处置动作**：每章一个明确动作（合并 / 删除 / 挪位 / 补阻碍 / 补钩子 / 提前爽点）。
8. **给加压清单**：列 3–5 条可直接插入的加压动作，指明插在哪章哪处。
9. **自检**：跑「网文节奏自检表」。

## 评分维度表

| 维度 | 0 分 | 5 分 | 10 分 |
|------|------|------|--------|
| 爽点密度 | 全章无爽点 | 一个弱爽点，或爽点被稀释 | 章内有明确爽点且当章闭环 |
| 进展感 | 读完不知发生了什么 | 有事件但说不清推进了什么 | 目标 / 阻碍 / 收获 / 悬念至少推进一项且清楚 |
| 钩子强度 | 章末平收，可随时停更 | 有悬念但泛泛（「似乎有什么不对」） | 指向下一章的具体问题或正在发生的动作 |
| 节奏拖沓 | 大段解释与赶路 | 有冗余段落但不致命 | 无冗余，长短段落交替 |
| 信息重复 | 重复已知设定与旧结论 | 部分重复 | 只在必要处复述，且复述有新角度 |

> 综合判定：均分 ≥ 7 为合格章；5–6 为待修；≤ 4 为塌陷章，必须给处置动作。

## 高潮频率检查

| 检查项 | 常见量级 / 参考区间 | 处置建议 |
|--------|-------------------|----------|
| 小高潮间隔 | 约每 3–5 章一次 | 间隔超过 5 章：把最近一次伏笔回收提前兑现 |
| 大高潮位置 | 每卷末一次 | 卷末缺高潮：把该卷 BOSS 战提前或加重代价 |
| 连续高强度 | 连续 3 章以上强爽点 | 插一个低强度但有收获的过渡章，让强度有对比 |
| 卷末兑现 | 大高潮必须兑现本卷承诺 | 兑现不足：补「结果落地 + 新状态」两段 |
| 钩子连续性 | 每章一个 | 断档章：章末改写成具体问题或动作 |

## 塌陷章归因表

| 主因 | 表现 | 加压手段 | 注意事项 |
|------|------|----------|----------|
| 无进展 | 只是赶路、闲聊、回忆 | 加一个具体阻碍，让目标受阻 | 阻碍要来自已有势力，不凭空造人 |
| 节奏拖沓 | 解释世界观、复述旧事 | 压缩解释到两句内，把设定放进冲突里说 | 不要删掉必要设定，改成被逼着说出的 |
| 信息重复 | 反复交代同一结论 | 换信息角度：让对手反驳一次 | 别直接删，读者可能刚追更 |
| 爽点缺席 | 主角持续被动挨打 | 给一次小兑现（升级 / 打脸 / 拿到资源） | 兑现要有依据，不能白给 |
| 钩子缺失 | 章末平收 | 章末改成一个正在发生的问题 | 钩子要与本章内容直接相关 |
| 主角被动 | 全靠巧合与他人推动 | 把一次关键机会改为主动争取 | 主动必须付出代价 |

## 加压手段清单

| 手段 | 做法 | 适合 |
|------|------|------|
| 加时限 | 给本章目标加截止时间 | 需要推动决策 |
| 换代价 | 让失败变贵（寿元、身份、关系） | 需要升级冲突 |
| 换信息 | 让角色知道一件改变判断的事 | 需要翻转认知 |
| 削选项 | 拿掉主角的退路 | 需要逼出选择 |
| 提前兑现 | 把已埋的伏笔回收提前 | 修补爽点间隔 |
| 借势打脸 | 让此前被轻视的一方当场见证反差 | 需要放大打脸效果 |
| 换视角 | 用对手视角写同一事件 | 需要增加压迫感 |
| 打断 | 外部事件打断当前动作 | 需要提节奏 |

## 网文节奏自检表

| 检查 | 通过标准 |
|---|---|
| 打分有依据 | 每维分数后面有一句可复核的正文依据 |
| 塌陷章已定位 | 所有均分 ≤ 4 的章都被列出并给了处置动作 |
| 处置动作具体 | 写「合并进第 N 章 / 把第 X 章的回收提前」，不写「再充实」 |
| 频率达标 | 小高潮间隔未超过 5 章，卷末有明确大高潮 |
| 强度有起伏 | 没有连续 3 章以上同强度高压 |
| 钩子不缺席 | 每章末都能写成一句具体问题 |
| 加压清单可落 | 每条加压指明插在哪章哪处 |
| 不破坏承诺 | 加压手段没有让已兑现的爽点失效 |

## 输出格式

````markdown
## 评分范围
- 章节：第 N–M 章　章数：<...>　基线：<作者自定 / 默认参考值>

## 逐章评分
| 章 | 爽点密度 | 进展感 | 钩子强度 | 节奏 | 信息重复 | 均分 | 爽点类型 | 判定 |
|----|----------|--------|----------|------|----------|------|----------|------|
| 1 | 6 | 7 | 5 | 7 | 8 | 6.6 | 打脸（弱） | 待修 |

## 节奏曲线
```
1 ── 6.6 ── 7.8 ── 3.9 ── 4.1 ── 9.2
          ▲平台期        ▲塌陷   ▲卷末大高潮
```

## 频率检查
- 小高潮间隔：<章号列表；最长间隔 N 章>
- 卷末大高潮：<有 / 无；位置第 N 章>
- 连续高强度：<章号；建议插入过渡章>

## 塌陷章处置
| 章 | 均分 | 主因 | 处置动作 | 影响 |
|----|------|------|----------|------|
| 4 | 3.9 | 无进展 + 钩子缺失 | 合并进第 5 章，并把第 9 章的伏笔回收提前 | <...> |

## 加压清单
1. 在第 3 章中让主角失去 <退路>，代价是 <...>
2. 把第 <N> 章才出现的 <线索> 提前到第 <M> 章露出
3. ...

## 结论
<整体节奏判断 + 优先修改的 3 章 + 下一批爽点的建议位置>
````

## 质量检查清单

- [ ] 每一维打分都附一句正文依据，不是整体印象；
- [ ] 频率检查写明小高潮间隔章号与卷末大高潮位置；
- [ ] 所有均分 ≤ 4 的章都被列为塌陷章并给了具体处置动作；
- [ ] 没有把「安静章」一律判为塌陷——低分但必要的章要单独说明；
- [ ] 加压清单每条都指明插入位置与代价来源；
- [ ] 加压建议没有靠反派降智或无代价馈赠来制造爽点；
- [ ] 强度过密处给出了插入过渡章的建议，而不是一味加料；
- [ ] 量级表述写成常见量级 / 参考区间，未引用平台榜单或订阅数据。
