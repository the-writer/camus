# 网文分卷与章节大纲（novel/online）

> 产出可直接日更的施工图：黄金三章定调、每卷一个目标与一次跃迁、逐章「目标—阻碍—收获 / 悬念 + 章末钩子」，并排出势力与地图的推进台阶。

## 用途

- 连载前排出整卷施工图，保证日更时每章都有活干、章末都能挂钩子。
- 用卷结构切分长线：每卷一个目标、一个阶段 BOSS、一次实力或身份跃迁。
- 用「黄金三章」保住开篇流失率：冲突、金手指、长线目标必须在第 1–3 章同时到位。
- 让地图与势力随主角成长同步扩大，避免「刚出新手村就打最终 Boss」。

## 何时使用

- 开坑后、写第一章之前；
- 一卷写完、要开下一卷时；
- 读者反馈「前期没劲」「后面拖」需要重新排布时；
- 要补写中段（拖沓段）或压缩长段（赶进度段）时。

## 创作进度

> 本技能的第一步是进度回顾：从 `.agents/memories/` 与作品数据源汇总「写到哪、写了多少、还差什么」，再进入具体工作。口径与模板见 `AGENTS.md` §5.4。

### 回顾步骤

1. **读记忆**：先读 `.agents/memories/project.md`、`outline.md`，再按需读 `characters.md`、`world.md`、`continuity.md`、`preferences.md`、`style.md`；目录或文件不存在就跳过，不视为错误。
2. **扫数据**：扫描源目录（`posts/`，不存在则 `src/`）的卷 / 章文件；若存在 `.workshop/`，按 `AGENTS.md` §5.5 读取设定卡、地名、关系与候选条目。
3. **统计**：按下表统计卷 / 章 / 字数、最近更新、伏笔回收、人物与设定条目；所有数值给出「来源」，无法从文件得到时标「未记录」，不估算、不编造。
4. **对齐**：记忆与正文冲突时以正文为准；回顾结论写回 `outline.md`（进度、伏笔）及受影响的类别文件。
5. **输出回顾**：先交付「进度回顾」块，再继续本技能后续的输入与执行步骤。

```markdown

- 上次更新：<日期 / 最新一章>（依据：<...>）

| 项 | 数值 | 来源 |
|---|---|---|
| 卷数 / 章数 | <...> | <...> |
| 已完成章节 | <...> | <...> |
```

## 输入

| 输入 | 说明 | 缺失时 |
|---|---|---|
| 选题与卖点 | 一句话卖点、金手指、读者承诺 | 必须有；缺失时先跑 `novel/online/premise-generator.md` |
| 人物档案与境界台阶 | 谁能上哪一阶 | 缺失时先跑 `novel/online/character-bible.md`，或临时拉一张草稿表 |
| 目标体量 | 总章数、卷数（常见量级：每卷 30–60 章，章均 2000–3000 字，实际以作者与平台情况为准） | 按「每卷 30–60 章、章均 2000–3000 字」的常见量级假设，并标注「待用户确认」 |
| 更新节奏 | 日更 / 周更 / 存稿量 | 按日更假设；存稿不足时优先缩短当前卷而不是压缩章纲颗粒度 |
| 结局方向 | 大结局是登顶、复仇、归隐还是掀桌 | 向用户确认；未确认时按「长线目标达成 + 反派清算」草拟 |

## 执行步骤

1. **定长线目标**：一句话写清主角最终要达成什么，拆成 3–6 个可卷化的阶段目标。
2. **切卷**：按「每卷一个目标 + 一个阶段 BOSS + 一次实力或身份跃迁」切卷，给每卷写卷名与卷末状态。
3. **排黄金三章**：逐章指定职责与最低要求，缺哪一项就补哪一项，不许顺延。
4. **排地图与势力台阶**：确定主角的起点层级（家族 → 宗门 / 学院 → 城市 → 区域 → 国家 → 大陆）与每层的目标 BOSS。
5. **写章纲**：逐章填「目标 / 阻碍 / 收获或悬念 / 章末钩子」，钩子必须指向下一章的具体问题。
6. **挂爽点**：把爽点承诺分配到具体章，标明是即时爽点还是伏笔回报。
7. **挂伏笔**：记录埋点章与计划回收章，登记到伏笔账本。
8. **配金手指**：标出本章金手指的使用与代价支付，并更新代价累计表。
9. **查密度**：每章至少推进「目标 / 阻碍 / 收获 / 悬念」中的一项；连续三章无进展必须处理。
10. **自检**：跑「网文大纲自检表」。

## 黄金三章职责表

| 章 | 最低要求 | 读者此刻得到 | 常见失误 |
|----|----------|--------------|----------|
| 第 1 章 | 立冲突：主角当下必须解决的具体麻烦；亮金手指的第一次使用；给出长线目标的方向（未必说全） | 主角是谁、他有什么不一样、他要往哪走 | 花了三章铺世界观，主角还在赶路 |
| 第 2 章 | 金手指的能力与代价同时露头；给一次小兑现（升级 / 打脸 / 拿到资源） | 这个金手指怎么用、要付什么 | 只展示能力不给限制 |
| 第 3 章 | 立长线目标：把方向写成可执行的任务或承诺；抛出第一个真正的对手或阻力 | 接下来要干什么、谁会挡路 | 目标只停留在「变强」这种空词 |

> 三章之内必须同时具备：立冲突 + 亮金手指 + 立长线目标；任何一项缺席，用后续章节补的代价通常更高。

## 章纲模板

```text
第 N 章 <标题>
- 视角：<谁>
- 本章目标：<视角人物这一章想达成什么>
- 阻碍：<什么在挡路，谁挡的>
- 收获 / 悬念：<得到什么 / 留下什么未解问题>
- 金手指：<用了哪项能力；支付了什么代价；累计到多少>
- 爽点：<即时爽点 / 伏笔回报；类型>
- 章末钩子：<指向下一章的具体问题或动作>
- 埋 / 收伏笔：<埋 A / 收 B>
```

> 钩子写法：写「下一章要回答的问题」或「一个正在发生的动作」，不写「欲知后事如何」。

## 节奏基线参考

| 项 | 常见量级 / 参考区间 | 说明 |
|----|-------------------|------|
| 每章推进量 | 至少 1 项（目标 / 阻碍 / 收获 / 悬念） | 低于此线的章视为填充章 |
| 小高潮间隔 | 约每 3–5 章一次 | 经验参考，非硬性规定；连续高强度时反而要留呼吸位 |
| 大高潮位置 | 每卷末一次 | 卷末是兑现点，不能挪到下一卷开头 |
| 黄金三章跨度 | 第 1–3 章 | 越晚补上，越难挽回 |
| 章末钩子 | 每章一个 | 钩子要与本章内容直接相关，不做无关预告 |

## 网文大纲自检表

| 检查 | 通过标准 |
|---|---|
| 黄金三章齐备 | 第 1–3 章同时有冲突、金手指、长线目标 |
| 每卷有闭环 | 目标、BOSS、跃迁三件齐全 |
| 跃迁有依据 | 境界或身份变化能追到触发事件与代价 |
| 章章有进展 | 没有连续三章只做铺垫或赶路 |
| 钩子具体 | 每章末能写成「下一章要回答的问题」 |
| 势力不跳级 | 没有在第 10 章就打上大陆级对手 |
| 爽点有位置 | 每条读者承诺都能在章纲里找到兑现章 |
| 代价有账 | 金手指每次使用都在章纲里记账 |

## 质量检查清单

- [ ] 黄金三章三件事齐备（立冲突 + 亮金手指 + 立长线目标），没有顺延到第 4 章以后；
- [ ] 每卷都写清了「一个目标 + 一个阶段 BOSS + 一次实力或身份跃迁」；
- [ ] 每次跃迁都能追到触发事件与付出的代价；
- [ ] 每章都有目标、阻碍、收获 / 悬念与章末钩子四要素；
- [ ] 章末钩子写成了具体问题或动作，不是悬念口号；
- [ ] 没有连续三章只做铺垫；填充章已标出处理动作；
- [ ] 地图与势力按家族 → 宗门 / 学院 → 城市 → 区域 → 国家 → 大陆逐层推进，未跳级；
- [ ] 量级表述标为常见量级 / 参考区间，未编造平台数据、榜单或订阅量。
