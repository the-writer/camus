# 创作脉络与大纲地图（novel/online）

> 把「大纲 + 正文 + 记忆 + `.workshop`」合成一张可核对的连载地图：分卷推进到哪、主线 / 支线 / 人物弧线各自停在哪、哪些设定资产还没用上、下一卷该接什么。

## 用途

- 在开新卷、长期停更后恢复、交接或复盘时，快速回答「现在写到哪、哪些线还开着、接下来写什么」。
- 把散落在 `outline.md`、正文、人物档案与 `.workshop` 中的信息合成一张结构地图，找出断线、空转与资源闲置。
- 对照分卷目标、地图与势力台阶，检查当前卷是否按计划推进、是否跳级。
- 为 `plot-outline.md` 提供输入：指出下一卷要收的账、可复用的设定资产与需要补的章。

## 何时使用

- 写完一卷、准备开新卷时；
- 连续多章「在推但没进展」，需要定位空转段时；
- 长期停更后恢复更新，需要先找回上下文时；
- 需要向编辑、合作者或读者说明当前进度与后续规划时；
- 发现人物、地点、伏笔在正文、记忆与 `.workshop` 之间对不上时。

## 创作进度

> 本技能的第一步是进度回顾：下文用 `<source>` 指源目录（`src/` 或 `posts/`）；从 `<source>/.agents/memories/` 与作品数据源汇总「写到哪、写了多少、还差什么」，再进入具体工作。口径与模板见 `AGENTS.md` §5.4。

### 回顾步骤

1. **读记忆**：先读 `<source>/.agents/memories/project.md`、`outline.md`，再按需读 `characters.md`、`world.md`、`continuity.md`、`preferences.md`、`style.md`；目录或文件不存在就跳过，不视为错误。
2. **扫数据**：扫描源目录（`posts/`，不存在则 `src/`）的卷 / 章文件；若存在 `.workshop/`，按 `AGENTS.md` §5.5 读取设定卡、地名、关系与候选条目。
3. **统计**：按下表统计卷 / 章 / 字数、最近更新、伏笔回收、人物与设定条目；所有数值给出「来源」，无法从文件得到时标「未记录」，不估算、不编造。
4. **对齐**：记忆与正文冲突时以正文为准；回顾结论写回 `outline.md`（进度、伏笔）及受影响的类别文件。
5. **输出回顾**：先交付「进度回顾」块，再继续本技能后续的输入与执行步骤。

### 回顾输出

```markdown
## 创作进度回顾
- 当前阶段：<开坑 / 连载中 / 修稿 / 完结>（依据：<...>）
- 上次更新：<日期 / 最新一章>（依据：<...>）

| 项 | 数值 | 来源 |
|---|---|---|
| 卷数 / 章数 | <...> | <...> |
| 已完成章节 | <...> | <...> |
| 总字数 / 章均字数 | <...> | <...> |
| 伏笔 | 埋 <X> / 收 <Y> / 未收 <Z> | <...> |
| 人物 / 地点 / 关系 / 候选 | <...> | <...> |
| `.workshop` 设定卡 | <... / 无> | <...> |

- 当前进度：<写到哪一卷哪一章，主线停在哪>
- 待续事项：<接下来 1–3 件，按优先级>
```

## 输入

| 输入 | 说明 | 缺失时 |
|---|---|---|
| 记忆 | `<source>/.agents/memories/` 中的 `outline.md`、`characters.md`、`world.md`、`continuity.md` | 缺失时从正文与 `.workshop` 重建，并标注「推断」 |
| 正文 | `posts/`（不存在则 `src/`）下的卷 / 章文件 | 无正文时按「只有大纲」模式分析，明确说明覆盖范围 |
| 主 SUMMARY.md | 站点元信息与目录结构 | 缺失时只按文件路径与标题分析 |
| `.workshop/`（可选） | 设定卡、地名、关系、候选与图谱 | 不存在时跳过，不视为错误 |
| 分析目标 | 复盘、开新卷、查断线、交接 | 未指定时按「全景复盘 + 下一步建议」执行 |

## 执行步骤

1. **做进度回顾**：按「创作进度」一节输出当前卷 / 章 / 字数与上次更新，作为本次分析的基线。
2. **建卷地图**：按目录与标题列出每卷的卷名、卷目标、当前状态（未开 / 进行 / 完成）、章段与卷末事件。
3. **对齐主线**：沿「长线目标 → 阶段目标 → 本卷目标 → 当前章目标」逐级检查，断在哪一级就标在哪一级。
4. **抽支线与伏笔**：从章纲和正文抽出势力线、情感线、资源线与伏笔，记录埋点、最近推进、计划回收与状态。
5. **对人物弧线**：对照 `characters.md` 与正文，标出主要人物的起点、当前状态、下一节点与最近出场章。
6. **查地图与势力台阶**：对照 `plot-outline.md` 的推进表，检查当前卷是否跳级、滞留或越级打 BOSS。
7. **交叉核对 `.workshop`**：按下面的规则把设定卡、地名、关系与候选同正文、记忆对照，列出差异。
8. **找缺口**：空转卷、无目标章、断线支线、超期伏笔、闲置设定、长期失踪人物。
9. **给下一步**：输出 1–3 个可执行动作（开新卷、补章、收伏笔、补设定卡），按优先级排序。
10. **回写记忆**：更新 `outline.md` 的进度与伏笔状态；必要时补 `characters.md`、`world.md`、`continuity.md`。

## 脉络识别口径（网文）

| 线索类型 | 从哪里找 | 判定标准 | 断线信号 |
|---|---|---|---|
| 主线目标 | `outline.md` 的长线目标、卷目标、章纲 | 每一级都能回答「为了什么」 | 章目标与卷目标无关 |
| 分卷推进 | 卷结构表 + 正文章节 | 每卷有目标、阶段 BOSS、一次跃迁 | 卷末没有状态变化 |
| 地图与势力 | 地图与势力推进表 | 家族 → 宗门 / 学院 → 城市 → 区域 → 国家 → 大陆逐层推进 | 越级打 BOSS、长期停在同一层 |
| 金手指线 | 能力表 + 代价累计表 | 每次使用有代价、有累计 | 只用不付代价、能力突然变强 |
| 爽点承诺 | 爽点排期 + 兑现章 | 每条读者承诺都有兑现章 | 承诺超期未兑现 |
| 伏笔 | 伏笔表 + 正文 | 埋点、推进、回收齐全 | 只埋不收、回收无铺垫 |
| 人物弧线 | 人物卡 + 出场章 | 每卷至少一次可追溯的变化 | 长期不出场、变化无事件支撑 |

## `.workshop` 交叉核对

> `.workshop/` 是创作资产库，不是事实来源；存在时按下表读取，不存在时整节跳过。

| 文件 | 提供什么 | 怎么用 |
|---|---|---|
| `project.md` | 项目总览、设定、总纲 / 章节清单 | 对照总纲与分析范围；它可能是计划，不等于正文进度 |
| `sheets.md` | 设定卡：人物名、族群、性别、职业、籍贯、关系、备注 | 建人物与关系底账；按 `##` 分卡、`- 字段: 值` 取字段 |
| `places.md` | 地名、族群、备注、结构 | 建地点底账，对照正文地点 |
| `relations.md` | 来源 / 目标 / 关系类型 | 校验人物关系与图谱连线 |
| `candidates.md` | 名称候选：族群、类型、性别、稀有度、字数、来源、收藏 | 找尚未使用的命名资产 |
| `graph.md` | 节点数 / 连线数与快照 | 快速核对数量、孤儿节点与孤立设定 |
| `preferences.md` | 生成规则与候选库筛选条件（JSON） | 只作生成偏好，不作情节事实 |
| `sheets.ini` | 人物 / 候选速查（INI） | 与 `sheets.md` 交叉核对，冲突以 `sheets.md` 为准 |
| `overview.md` | 可为空 | 空文件直接跳过 |

**冲突优先级**：正文 > 用户新指令 > `<source>/.agents/memories/` > `.workshop/`。冲突处必须标注「正文与卡片不一致」并给出处理建议，不能静默采信任何一方。

AI **只读** `.workshop/`，不修改这些文件；核对结论写回 `<source>/.agents/memories/`（`outline.md`、`characters.md`、`world.md`、`continuity.md`）。

## 质量检查清单

- [ ] 进度数据都有来源，未知项标了「未记录」，没有估算冒充统计；
- [ ] 每卷都有目标与状态，空卷、空转卷已单独标出；
- [ ] 主线能从长线目标一路追到当前章，断点位置明确；
- [ ] 每条支线与伏笔都记录了埋点、最近推进与回收状态；
- [ ] 人物弧线与出场章对得上，长期失踪人物已列出；
- [ ] 地图与势力未跳级，或跳级有触发事件与代价说明；
- [ ] `.workshop` 存在时已完成交叉核对，不存在时没有编造卡片内容；
- [ ] 冲突按「正文 > 用户指令 > 记忆 > `.workshop`」处理并标注；
- [ ] 「下一步」不超过 3 件，且按优先级排序。
