# 网文人物档案与金手指档案（novel/online）

> 产出可长期维护的双档案：人物档案（主角团 / 对手 / 反派 / 导师的定位与成长路线）与金手指档案（能力清单 + 代价累计）。

## 用途

- 连载期保持人物一致性：谁是谁的师兄、谁欠谁一条命、谁现在什么境界，不能靠记忆。
- 防止配角沦为工具人：配角在自己的场景里必须有独立于主角的诉求。
- 用等级 / 境界台阶表管住战力：跨阶要有条件、有代价，不能为爽而跳级。
- 用代价累计表管住金手指：读者能算出主角还剩多少寿元可用。

## 何时使用

- 开写前建立人物与金手指双档案；
- 每写完一卷做一次人物与战力盘点；
- 有人物行为「不像他会做的」时；
- 配角戏份明显不足、读者记不住时；
- 校对时检查境界、称呼、关系、代价是否前后一致。

## 输入

| 输入 | 说明 | 缺失时 |
|---|---|---|
| 选题与卖点 | 一句话卖点、金手指设定 | 必须有；缺失时先跑 `novel/online/premise-generator.md` |
| 已有正文线索 | 已出现的人物、称呼、境界、道具 | 扫描正文抽取，标注「正文推断」 |
| 升级体系 | 境界名称、阶数、突破条件 | 未给则按通用玄幻/都市口径生成 5–8 阶草稿并标注「待用户确认」 |
| 目标读者与篇幅 | 决定主角团规模与成长跨度（常见量级：主角团 3–6 人） | 按「主角团 3–6 人」假设并说明 |
| 战力天花板 | 主角最终能达到的层级 | 向用户确认；未确认时只规划近中期 |

## 执行步骤

1. **列人物**：从正文与大纲抽出所有有名有姓的人物与代称，标注出场次数与最后出场章。
2. **分功能位**：按「主角 / 主角团 / 对手 / 反派 / 导师 / 工具人风险」给每人归位，说明依据。
3. **写外在目标与成长路线**：每个主要人物写「他现在要什么 → 为此要做什么 → 得到什么 → 付出什么」。
4. **排成长路线**：把人物挂到「等级 / 境界台阶表」的某一阶，写明起点阶、目标阶、突破条件与该阶要付的代价。
5. **写关系与欠账**：用功能性关系描述（「A 要 B 给的 / B 欠 A 的」），不写「朋友」「敌人」这类空标签。
6. **做金手指能力表**：逐项列能力、触发条件、效果、限制、使用次数。
7. **做代价累计表**：把每次使用记成一行，累计代价写到当前章，标出临界点。
8. **查工具人风险**：对每个配角问一句「删掉他，这本书损失什么」，答不上来的标为工具人风险。
9. **做一致性检查**：对照正文，找出称呼、境界、关系、已用能力与档案冲突处。
10. **自检**：跑「网文人物自检表」。

## 人物功能位对照

| 功能位 | 作用 | 典型行为 | 风险 |
|--------|------|----------|------|
| 主角 | 承载成长与爽点 | 主动选择，承担代价 | 全程被动、靠巧合推进 |
| 主角团 | 分担视角、提供反应面 | 各有不可替代的功能 | 功能重叠、抢戏或沦为背景板 |
| 对手 | 当前阶段的对抗面 | 与主角同层或高一阶，赢在信息或资源 | 只会嘲讽、没实力、专供打脸用 |
| 反派 | 长线敌手 | 有自己的目标与资源，能持续施压 | 只会降智、每次都输、坏得没有逻辑 |
| 导师 | 提供信息、资源、传承 | 有限度地帮忙，会设限 | 随叫随到、替主角解决所有问题 |
| 工具人风险 | 只为推进情节存在 | 被需要时出现，用完消失 | 无自身诉求、无名字、无记忆点 |

## 网文人物自检表

| 检查 | 通过标准 |
|---|---|
| 功能位清晰 | 每人归位明确，工具人风险已单独标出 |
| 目标可连载 | 外在目标不是一章能完成的小事 |
| 成长有条件 | 每个境界跃迁写清条件与代价 |
| 战力不跳级 | 跨阶处有依据，且在正文能找到对应铺垫 |
| 金手指有边界 | 能力表每项都有「不能做」 |
| 代价可结算 | 代价累计表能算出主角还剩多少余量 |
| 配角有诉求 | 主角团成员各有独立于主角的目标 |
| 对手有实力 | 对手不是专供打脸的软柿子 |

## 质量检查清单

- [ ] 每个主要人物都归了功能位，工具人风险单独列出而非混在总表里；
- [ ] 外在目标与成长目标分两栏写清，目标能支撑多章；
- [ ] 每个境界台阶都写了进入条件、突破条件与突破代价；
- [ ] 压制关系写明默认「高一阶压低一阶」，越阶处有依据；
- [ ] 金手指能力表每项都有「限制 / 不能做」，没有一项是无条件生效；
- [ ] 代价累计表按章留痕，累计值与单次代价同单位、可结算；
- [ ] 主角团成员各有独立于主角的诉求，不是主角的附属品；
- [ ] 未凭空新增正文中不存在的人物、境界或道具。
