# 网文设定与战力连续性审查（novel/online）

> 用五本台账审查连载期的一致性：境界台阶、道具品阶与数量、金手指次数与代价累计、时间线、伏笔账本，并专项排查战力跳变与设定闲置。

## 用途

- 连载期抓硬伤：境界顺序错乱、道具数量对不上、代价没记账、伏笔埋了不收。
- 防止战力跳变：主角突然变强，读者算不出依据。
- 防止设定闲置：金手指的分支、族谱、法宝体系写了很多，后面再没出现。
- 给可执行的修改清单，而不是笼统的「再核对一遍」。

## 何时使用

- 每写完一卷做一次；
- 每 10–20 万字做一次（连载期常见量级，按作者实际体量调整）；
- 读者提出「前后矛盾」反馈时；
- 准备开新卷、引入新势力或新境界体系前；
- 全书完结后的终审。

## 创作进度

> 本技能的第一步是进度回顾：从 `.agents/memories/` 与作品数据源汇总「写到哪、写了多少、还差什么」，再进入具体工作。口径与模板见 `AGENTS.md` §5.4。

### 回顾步骤

1. **读记忆**：先读 `.agents/memories/project.md`、`outline.md`，再按需读 `characters.md`、`world.md`、`continuity.md`、`preferences.md`、`style.md`；目录或文件不存在就跳过，不视为错误。
2. **扫数据**：扫描源目录（`posts/`，不存在则 `src/`）的卷 / 章文件；若存在 `.workshop/`，按 `AGENTS.md` §5.5 读取设定卡、地名、关系与候选条目。
3. **统计**：按下表统计卷 / 章 / 字数、最近更新、伏笔回收、人物与设定条目；所有数值给出「来源」，无法从文件得到时标「未记录」，不估算、不编造。
4. **对齐**：记忆与正文冲突时以正文为准；回顾结论写回 `outline.md`（进度、伏笔）及受影响的类别文件。
5. **输出回顾**：先交付「进度回顾」块，再继续本技能后续的输入与执行步骤。

## 输入

| 输入 | 说明 | 缺失时 |
|---|---|---|
| 已写正文 | 至少覆盖被审卷的完整内容 | 必须有 |
| 境界 / 等级台阶表 | 阶名、突破条件、压制关系 | 缺失时先跑 `novel/online/character-bible.md` 生成草稿表，并把判定标为「待用户确认」 |
| 金手指能力表与代价累计表 | 能力、限制、已用次数、累计代价 | 缺失时从正文反推重建草稿，标「正文推断」 |
| 道具品阶表 | 品阶序列、稀有度、来源与去向 | 缺失时按正文出现顺序建临时品阶，标「推断」 |
| 伏笔账本 | 埋点与回收登记 | 缺失时从正文重建，并标「待核实」 |
| 卷目标与章纲 | 用于判断「该出现却没出现」 | 缺失时只做文内自洽审查，不做完整性判断 |

## 执行步骤

1. **建境界台账**：逐章记录每个有战力人物所在阶、突破事件与突破条件，核对顺序与压制关系。
2. **建道具台账**：逐件记录品阶、数量、获得章、使用 / 消耗章、当前持有人。
3. **重建金手指账**：把每次能力使用记成一行，核对使用次数、限制是否被绕过、代价是否漏记。
4. **排时间线**：把事件按故事时间排序，核对日程、伤势恢复、赶路耗时与「三天后」类表述。
5. **查伏笔账本**：核对每个伏笔的埋点、承诺内容与回收点，确认兑现与埋点一致。
6. **查战力跳变**：对比相邻章的战力表现，找出没有触发事件、突破条件或代价支撑的增强。
7. **查设定闲置**：统计每个设定项（能力分支、法宝、族谱、势力、地名规则）的出现次数，标出「立了就没再用过」。
8. **查对手降智**：回看反派与对手的决策是否为了衬托主角而失去合理性。
9. **分级输出**：致命 / 显要 / 轻微，每条给具体改法。
10. **自检**：跑「网文连续性自检表」。

## 审查维度表

| 维度 | 检查什么 | 典型问题 |
|------|----------|----------|
| 境界顺序 | 阶名与阶序全书一致；突破条件未被随意放宽 | 第 30 章说「筑基需三味真火」，第 80 章主角无火突破 |
| 突破条件 | 每次突破有触发事件、有代价 | 主角睡一觉就升阶 |
| 压制关系 | 高一阶压低一阶的默认关系未被无声打破 | 对手高两阶却被一招秒杀且无解释 |
| 道具品阶 | 品阶序列稳定；高阶道具的出现有来源 | 法宝凭空升阶、同一件道具前后品阶不同 |
| 道具数量 | 数量守恒：获得、消耗、转赠可对上 | 丹药用完又出现、灵石数目对不上 |
| 金手指次数 | 每次使用有记录；限制未被绕过 | 限制写着「每日一次」，本章用了三次 |
| 代价累计 | 每次使用都扣代价，累计值与临界点一致 | 寿元代价写了却从不结算，主角永不老 |
| 时间线 | 日程、伤势、赶路耗时与前文相加成立 | 同一晚出现在两个相隔千里的地方 |
| 伏笔 | 埋点承诺与回收内容一致 | 埋时说「身世之谜」，回收时换了件事 |
| 战力跳变 | 每次增强都能追到触发与代价 | 见下方专项 |
| 设定闲置 | 每个设定项在后续被再次使用 | 见下方专项 |

## 战力跳变专项

| 跳变形态 | 识别方法 | 处理建议 |
|----------|----------|----------|
| 无因增强 | 战力数字 / 表现变强，前文找不到触发 | 补一句触发事件，或回退到原阶 |
| 无代价突破 | 突破没有身体 / 资源 / 寿元损耗 | 给突破加一项代价，并回填到代价累计表 |
| 越阶无据 | 打赢明显高阶的对手却无解释 | 补「凭什么」（功法 / 道具 / 信息 / 地形），或改为险胜 |
| 招式突然出现 | 新能力 / 新招此前无铺垫 | 提前埋一次使用痕迹，或改为借外力 |
| 反派降智 | 对手做不出于自身利益与认知的决策 | 给对手一个合理动机，让输在变量而非智力 |

## 设定闲置专项

| 闲置类型 | 常见表现 | 处理建议 |
|----------|----------|----------|
| 金手指分支 | 列了三项能力，实际只用过一项 | 删掉未用分支，或安排一次针对性的使用场景 |
| 法宝 / 道具谱系 | 列了品阶表，只用最低阶 | 删表，或让一件道具在卷末兑现 |
| 族谱 / 势力设定 | 铺了很多家族关系，从未登场 | 保留与主线相关的，其余合入背景叙述 |
| 地理规则 | 写了「某地不可动用修为」却再未回去 | 安排一次返回该地的章节，或删掉该规则 |
| 境界体系 | 高阶只出现名字，无任何场景 | 给该阶安排一场展示或一场压制战 |

## 严重度分级

| 级别 | 定义 | 处理 |
|------|------|------|
| 致命 | 改变情节逻辑的硬伤（人死了又出现、境界顺序错乱、代价凭空归零） | 必须改 |
| 显要 | 削弱可信度（道具数量对不上、限制被绕过、时间线冲突） | 尽量改 |
| 轻微 | 表述不一致（同一物两个称呼、品阶叫法不同） | 可留，或统一措辞 |

## 质量检查清单

- [ ] 境界台账覆盖所有有战力的角色，阶序与突破条件逐条核对；
- [ ] 道具台账做到数量守恒，消耗与转赠都有去向；
- [ ] 金手指账按章留痕，限制被绕过的地方明确标出；
- [ ] 代价累计值与单次代价同单位，临界点与正文描写一致；
- [ ] 时间线与伤势、赶路耗时可相加成成立；
- [ ] 伏笔账本中每条都有状态（已回收 / 待回收 / 明确留白）；
- [ ] 战力跳变与设定闲置各自成表，每条给了具体处置；
- [ ] 未提供的输入在「审查范围」里写明，并跳过相关检查而非凭空下结论。
