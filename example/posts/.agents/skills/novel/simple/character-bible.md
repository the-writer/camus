# 人物档案与生活细节（novel/simple）

> 建立可持续维护的人物档案：动机链、功能性关系网、生活细节清单与语言特征，并跑一致性检查。

## 用途

- 让人物有可演的行为逻辑，而不是作者推动剧情的工具。
- 把「人物」落到具体生活上：职业、居住、习惯、身体特征、钱与通勤——细节能反过来生成故事。
- 在长篇里保持人物一致，避免「前后不一样」。
- 让不同的人说话听得出区别，且差异有理由（年龄、地区、职业、亲疏）。
- 排查动机断裂：人物为什么这么做说不通。

## 何时使用

- 开写前建立人物档案；
- 写到人物行为「不像他会做的」时；
- 需要给配角加戏份、或合并功能重复的角色时；
- 校对阶段检查人物设定与正文的矛盾。

## 输入

| 输入 | 说明 | 缺失时 |
|---|---|---|
| 故事核 / 一句话梗概 | 人物所处的冲突 | 必须有；缺失时先做 `premise-generator.md` |
| 已有正文片段 | 出现过的人物、称呼、关系、细节 | 扫描输入材料抽取，抽取不到的标注「待补」 |
| 人物功能 | 主角 / 对手 / 盟友 / 镜子 / 门槛 | 从梗概推断并与用户确认 |
| 时代与地域 | 影响生活细节、职业与制度细节 | 未指定时按「当代现实向」假设并说明 |
| 职业领域 | 需要写实的行业或生活领域 | 向用户确认；未确认时只写通用生活细节，不写具体行业规程 |

## 执行步骤

> 动机链、关系网写法、语言 / 称谓维度、工具人检查与通用一致性表见 `.agents/shared/novel-character.md`；本技能只写生活细节与专项检查。

1. **列人物**：从正文抽取所有有名有姓的人物与代称，标注出场次数与所属场景。
2. **分配功能**：标注每人承担的叙事功能（主角 / 对手 / 盟友 / 导师 / 镜子 / 门槛 / 施压者），没有功能的角色列入合并或删除建议。
3. **填动机链**（每个主要人物）：按 `.agents/shared/novel-character.md` §1 的模板逐项填写；缺项写「待补」。
4. **写关系网**：按 `.agents/shared/novel-character.md` §2 的功能性写法，不写「A 是 B 的朋友」这类标签。
5. **填生活细节清单**：职业、居住、习惯、身体特征（另可补钱与通勤通讯、医疗与制度、家庭结构与称谓、季节与气候）。每条细节后附一行「能生出的故事」，答不上来的删掉。
6. **定语言特征**：按 `.agents/shared/novel-character.md` §3 的维度填写；重点写与生活处境相关的用词与沉默方式。
7. **跑一致性检查**：对照正文找出行为与档案冲突处，逐条给出改法；通用项见 `.agents/shared/novel-character.md` §5。
8. **输出档案表**与合并 / 删除建议。

## 生活细节清单

| 类别 | 要写到什么程度 | 能生出的故事（示例问法） |
|---|---|---|
| 职业 | 术语、流程环节、收入量级、工作时间 | 哪一步流程会让他迟到、丢单、被扣钱？ |
| 居住 | 楼层、户型、噪音、采光、邻里关系 | 邻居听见了什么？他为什么不肯搬走？ |
| 习惯 | 小动作、固定时段、消费与 wasting 习惯 | 这个习惯在什么场合会暴露他？ |
| 身体特征 | 身高、体型、伤病、视力听力、衰老痕迹 | 哪句台词会因为听力问题没听清？ |
| 钱 | 收入量级、固定支出、可动用余额 | 这笔钱够不够撑到发工资那天？ |
| 通勤与通讯 | 路程耗时、交通方式、消息到达时差 | 谁会因为一条没能及时收到的消息做错决定？ |
| 医疗与制度 | 病程限制、请假与报销等手续常识 | 手续卡在哪一步？他为什么不肯去办？ |
| 家庭结构与称谓 | 谁跟谁住、怎么称呼、谁不在了 | 为什么在这个称呼上他停顿了一下？ |
| 季节与气候 | 当季气温、衣物、作息、作物 | 天气怎样改变了他的计划？ |

> 每条细节写成「<具体描述> ｜ 来源：<正文设定 / 推断 / 待核实> ｜ 能生出的故事：<...>」。来源为「推断」的必须标出，作者未确认前不能当定论用。

## 一致性检查表

> 通用项（行为可解释、目标与需求不同、秘密有代价、关系非对称等）见 `.agents/shared/novel-character.md` §5；本表只列生活向专项。

| 检查 | 通过标准 |
|---|---|
| 细节可生故事 | 每条生活细节都能说出生出哪个冲突；说不出的已删 |
| 细节不打架 | 职业、时间、钱数、称谓、年龄互不矛盾 |

## 质量检查清单

- [ ] 每个主要人物都有完整动机链，缺项标注「待补」而不是留空；
- [ ] 外在目标与内在需求**不同**，相同的一律重写；
- [ ] 错误信念能解释至少两次错误决策；
- [ ] 关系描述里没有出现「朋友」「敌人」这类空标签，且每组关系双向不对称；
- [ ] 生活细节覆盖职业 / 居住 / 习惯 / 身体特征四类，且每条都写得出「能生出的故事」；
- [ ] 语言特征具体到可模仿，遮住人名能认出说话人；
- [ ] 一致性问题都给出了明确处理方式（改动机 / 改行为 / 加过渡三选一）；
- [ ] 涉及真实职业规程、医疗与制度流程的表述保持概括，需核实处标「待核实」，未编造条款与来源。
