# 核心设定与主题（novel/simple）

> 从一个真实处境出发，产出「一句话梗概 + 控制主题 + 人物困境 + 生活质感锚点 + 边界尺度 + 三个备选方向」。

## 用途

- 把一个模糊念头落成可写下去的故事核，不依赖任何类型套路（普通小说 / 现实向基线）。
- 在开写前定死「作者想说的话」，避免写到中途变成无主题的流水账。
- 让人物先于事件成立：冲突来自人物的欲望与局限，而不是外部事件堆叠。
- 用生活质感锚点替代设定罗列，让细节能反过来生成故事。
- 在多个可行方向之间做取舍，而不是凭「哪个听着更带感」选一个。

## 何时使用

- 开新坑之前，需要从素材推导出故事核；
- 已有梗概，但说不清「这篇到底想说什么」；
- 写到中段发现主线涣散、人物只是在被事件推着走，需要重新锚定；
- 需要为系列 / 同题材多篇作品统一基调与边界。

## 输入

| 输入 | 说明 | 缺失时 |
|---|---|---|
| 灵感碎片 | 一个画面、一个人、一段关系、一句听来的话 | 必须有（哪怕只有一句） |
| 题材与气质 | 现实向、年代感、社会派、情感、悬疑等倾向 | 向用户确认；未确认时按「当代现实向」假设并说明 |
| 篇幅与形态 | 短篇 / 中篇 / 长篇 / 连续故事单元 | 未指定时按「中篇小说」假设并说明 |
| 时代与地域 | 大致年代与地点，影响生活细节与制度细节 | 向用户确认；未确认时按「当代、非特定城市」假设并说明 |
| 边界与尺度 | 不写什么（题材禁区、暴力程度、情感伦理、结局调性） | 必须问；用户未答时列出默认边界并标注「待确认」 |
| 已有素材 | 旧稿片段、真实经历改编、既有设定 | 扫描输入材料抽取可用素材，其余标注「待补」 |

## 执行步骤

1. **从人开始，不从事件开始**：写下「谁」——一个具体到有职业、有处境的人；再写下「他此刻正被什么卡住」。若第一步只能写出事件（车祸、分手、辞职），回到素材里把事件中那个人挖出来。
2. **拆欲望与局限**：写两行——他**嘴上要什么**（外在目标）、他**其实缺什么**（内在需求）；再写他**做不到什么**（局限：身份、时间、钱、习惯、性格）。冲突 = 追求外在目标的过程中不断撞上内在需求与局限。
3. **写控制主题**：一句话，作者想用这个故事说的话。主题必须是**判断**，不是话题；「亲情」是话题，「照顾有时候是一种控制」是判断。
4. **给主题找证明路径**：写出 3 个「由人物的选择来证明主题」的时刻（他做了什么、付出了什么代价）。一个都写不出来，说明主题目前只是旁白宣言，需要重写。
5. **写一句话梗概**：用「<某人>，<身份与处境>，<必须面对的具体问题>，<必须做出的选择>，<否则失去什么>」句式，控制在 40 字内。
6. **埋生活质感锚点**：至少 5 条，具体到可验证（职业、居住、季节、家庭结构、钱的量级、通勤与通讯、医疗与制度）。每条都要回答一句：**这个细节能生出哪个冲突或选择**。答不上来的细节删掉。
7. **定边界与尺度**：写清不写什么、避开哪些套路、结局调性的上限与下限。
8. **列三个备选方向**：同一素材的三种走法，要求**冲突来源不同**（不是同一故事的三种措辞），各自标注差异点、代价与风险。
9. **过一致性自检表与忌讳清单**：不合格项当场改掉，不要记成「以后再说」。

## 「主题—冲突—生活锚点」一致性自检表

| 检查 | 通过标准 |
|---|---|
| 主题是判断 | 能改写成一句有立场的话；不是「亲情 / 成长 / 孤独」这类话题 |
| 主题可被证明 | 存在至少 3 个人物选择时刻承担主题，且都不是旁白宣布 |
| 冲突内生 | 拿掉外部反派或事故后，冲突仍然成立（人的欲望与局限仍在） |
| 人物先于事件 | 每个关键转折都由人物行动触发，事件只是触发条件 |
| 梗概含代价 | 梗概里能读出「不选会失去什么」 |
| 锚点可生故事 | 每条生活锚点都能回答「它逼出了哪个选择」 |
| 细节不打架 | 时间、季节、年龄、钱数、家庭结构之间没有互相矛盾 |
| 边界可执行 | 边界写得能判断一段情节「要不要写」 |

## 普通小说忌讳清单

- **狗血套路无铺垫**：失忆、亲子掉包、突然出现的富亲戚、天降好运，都不能只靠一句「其实早就……」补叙。
- **靠巧合收尾**：结局的关键推动力必须来自人物早先的选择或长期积累，而不是「正好赶上」。
- **人物只为推动剧情**：任何一次反常行为都要能追溯到档案里的欲望、恐惧或错误信念。
- **说教式结尾**：不写「他终于明白了……原来……」式的总结独白；结尾落在后果、动作或沉默上。
- **内心独白直接解释主题**：不让人物想出主题句；主题由读者从他做的选择里读出来。
- **细节自相矛盾**：职业、时间、钱的量级、称呼、地理必须自洽。
- **凭空虚构现实**：不编造法律条文、医疗流程、职业规程的具体条款与来源。

- 主题（作者想说的话）：<一句有立场的判断>
- 明确回避的说法：<不打算写成什么>

## 质量检查清单

- [ ] 一句话梗概里同时有人物、具体问题、选择与代价；
- [ ] 控制主题是一句可站住的判断，不是话题或金句堆砌；
- [ ] 主题有至少 3 个「由选择证明」的时刻，没有一句旁白替读者下结论；
- [ ] 冲突能在拿掉外部反派后依然成立（人物驱动的检验）；
- [ ] 生活质感锚点每条都能说出「它逼出了哪个选择」，且覆盖职业 / 居住 / 季节 / 家庭称谓 / 钱与通勤 / 医疗制度中的多数类别；
- [ ] 三个备选方向的冲突来源确实不同，不是同一故事的三种措辞；
- [ ] 忌讳清单逐条检查过，没有狗血套路、巧合收尾、说教式结尾；
- [ ] 涉及现实制度、法律、医疗、职业规程的表述保持概括，需核实处已标注「待核实」，没有编造条款与来源。
