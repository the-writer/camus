# 日常对白打磨（novel/simple）

> 把对白改成真实的人说的话：口语、身份有别、话里有话、删掉应答词仍读得懂。

## 用途

- 修掉「说明书式对白」「一问一答式对白」「两个信息交换器」。
- 用身份与关系差异拉开每个人的声音，而不是靠口头禅硬造。
- 用潜台词与信息差替代直白陈述，让重要的话不必说出口。
- 保持日常口吻，避免角色替作者说话（作者腔）。

## 何时使用

- 初稿完成后精修对白；
- 读起来像剧本说明书、或像两个人在交换信息时；
- 多人物场景里读者分不清谁在说话时；
- 需要为某段对话增加压迫感、尴尬或喜剧感时。

## 输入

| 输入 | 说明 | 缺失时 |
|---|---|---|
| 对白片段 | 待打磨的原文 | 必须有 |
| 场景目标 | 这段对话里每人想拿到什么 | 向用户确认；从上下文推断并标注「推断」 |
| 人物档案 | 各自的目标、秘密、语言特征 | 缺失时先做 `character-bible.md` |
| 场景元信息 | 地点、在场者、权力关系、时段 | 从正文抽取；缺失项标注「待补」 |
| 时代与地域 | 决定语体与词汇 | 未指定时按「当代」假设并说明 |

## 执行步骤

1. **标注意图**：给每句对白写「说话人此刻想从对方那里得到什么」。写不出来的句子是废句。
2. **标语域**：谁对谁说、亲疏远近、权力差、场合正式度、当时在做什么——先定语域，再动手改词。
3. **做口语化处理**：碎句、重复、倒装、吞字、填充词、话说一半改口。删掉「他说道 / 她说道 / 他说」这类报告式标签。
4. **拉开身份差异**：按语感差异表检查年龄、地区、职业、亲疏、权力、场合是否真的体现在句长、词与称谓上。
5. **找直白处**：凡是「说出真相、说出感受、说出请求」的句子都是候选；改为动作、替换句、物件承载或沉默。
6. **补潜台词与信息差**：给每句重要对白写一句「没说出口的真实意思」，并列出谁知道什么、谁不知道、谁误以为什么。
7. **清理应答词与寒暄**：删掉「嗯」「是啊」「你说得对」「好」「然后呢」后，段落仍然读得懂吗？读不懂就重写。
8. **朗读检查**：念出声，标出拗口、绕口、念不顺与信息过载的句子。
9. **分声线核对**：遮住人名，逐句确认能认出说话人。

## 语感差异表

| 差异源 | 体现在 | 例 |
|---|---|---|
| 年龄 | 句长、抽象词多少、玩笑方式 | 年轻人偏短句与俚语；长辈偏省略与套话 |
| 地区 | 方言词、语音、语序、称谓 | 南北差异体现在用词与尾音，不写「他说话很北方」这种标签 |
| 职业 | 术语、量词、对风险的措辞 | 医护谈指标与数值，工人谈活儿与工钱 |
| 亲疏 | 称呼、开玩笑的许可、抱怨的分寸 | 熟人才敢不回答，敢不接话 |
| 权力 | 句式、是否容许打断、是否用封闭式问题 | 上位者多用祈使句与只给一个答案的问句 |
| 场合 | 正式度、该省的字该省的话 | 家里一句话能省掉的信息，在会议上不能省 |
| 情绪 | 语速、句长、是否重复 | 越慌越重复；越怕越慢 |

> 差异必须落在**具体的词与句式**上；只写标签不写表现，等于没写。

## 潜台词与信息差

每句重要对白写两行：**说了什么** / **真正想说什么**。

| 原句（直白） | 改写（潜台词） | 手法 |
|---|---|---|
| 「我很担心你。」 | 「你今天回来得早。」 | 用观察代替情感宣告 |
| 「你走吧，我不爱你了。」 | 「钥匙留下吧，那把你用不上。」 | 用物件承载决定 |
| 「对不起，我骗了你。」 | 「那天我在车站等了很久。」 | 用回忆回避正面承认 |
| 「你在害怕。」 | 「把灯开大一点。」 | 用指令掩盖洞察 |

信息差表：谁知道什么、谁不知道、谁误以为——冲突应当由**信息差**产生，而不是由音量产生。

## 应答词清理

1. 把「嗯 / 是啊 / 你说得对 / 好的 / 然后呢 / 哦」整段删掉（暂不删语气词与停顿词）。
2. 通读：段落是否仍然讲得清？谁在回应谁？
3. 读不懂的地方说明这段对白靠寒暄维系，需要补**动作**或**真正的信息差**。
4. 少量应答词可以保留，但只用来做节奏（迟疑、敷衍、心不在焉），且要靠动作区分。

## 朗读检查

- 念出声，标出**念不顺**的句子（过长、书面词、双关读不出）；
- 标出**作者腔**：角色说出了作者想说的话，而不是人物会说的话；
- 标出**信息过载**的一句塞了多个信息，需要拆成几句；
- 标出**重复**：同一个信息说了两遍；
- 标出**没有动作的对白**：整段纯说话，像会议纪要。

## 忌讳

- **一问一答式**：人物只提问不回避，只回答不撒谎。
- **信息交换器**：为让读者知道设定而让人物互相通报。
- **角色替作者提问**：为了推进剧情，让人物问出明知故问的蠢问题。
- **所有角色同腔**：遮住人名认不出人。
- **把重要的话说破**：情感与真相直说，张力归零。

## 质量检查清单

- [ ] 每句重要对白都写出了「没说出口的真实意思」；
- [ ] 直白的情感句与真相句已被动作、替换句或沉默取代；
- [ ] 删除全部应答词后段落仍然读得懂；
- [ ] 对白中有动作、停顿或感官细节，不是纯说话；
- [ ] 遮住人名能认出说话人，差异落在具体词句而非标签；
- [ ] 没有「一问一答」与「信息交换器」式的对白，角色不替作者提问；
- [ ] 没有把人物口吻写成作者口吻（作者腔）；
- [ ] 改写没有改变剧情信息量与人物关系。
