# 结构与章节大纲（novel/simple）

> 按篇幅选定结构，把故事核展开成场景清单与章节大纲，并挂上人物弧线、伏笔与篇幅分配。

## 用途

- 写前排出章节级蓝图，避免写到一半失去方向。
- 按篇幅选结构：短篇不套长篇的骨架，长篇不靠逐场硬撑。
- 判断哪些内容该写成场景（scene）、哪些该压缩成概述（summary）。
- 检查节奏：转折前的铺垫够不够，收束是否拖沓。
- 把长篇拆成可发布的章节 / 单行本 / 分卷。

## 何时使用

- 开写长篇或系列前；
- 结构感觉「中段塌陷」「结尾仓促」时；
- 需要把已有草稿重新编排、压缩或扩写时；
- 需要把故事拆成若干可独立发布的单元时。

## 输入

| 输入 | 说明 | 缺失时 |
|---|---|---|
| 一句话梗概 | 故事核 | 必须有；缺失时先做 `premise-generator.md` |
| 人物档案 | 各角色的目标与弧线 | 缺失时先用 `character-bible.md` 补 |
| 目标篇幅 | 决定结构、章数与章长 | 未指定时按「中篇 / 8–25 章」假设并说明 |
| 主题与边界 | 决定哪些事件属于本故事 | 向用户确认，或从梗概推断并标注「推断」 |
| 已有草稿 | 需要重排或压缩的文本 | 无草稿时按从零规划处理 |

## 执行步骤

1. **定篇幅与结构**：按「按篇幅选结构」表选定一套结构，写清理由（不是三幕也可以，但必须有名有姓的结构来源）。
2. **定转折骨架**：列出 3–5 个转折点，每个写成「<谁> 在 <什么处境> 下做出 <什么选择>，导致 <什么不可逆的后果>」。转折必须由人物行动触发。
3. **切场景 / 概述**：按「场景与概述的取舍规则」把全篇内容分流；关键选择一律写成场景。
4. **排章节**：每章一句话写清「谁想要什么 → 遇到什么阻碍 → 结果如何」，并标注本章的场景 / 概述构成。
5. **挂人物弧线**：把每个人的弧线节点挂到具体章节，写明每一步的代价。
6. **标伏笔**：列出「在第 X 章埋、第 Y 章回收」的伏笔与它承诺的内容。
7. **分配篇幅**：按篇幅分配表给出各部分占比，标出压缩与展开的取舍。
8. **体检**：跑「结构自检表」，失衡就调章数与位置，而不是靠加戏补救。

## 按篇幅选结构

| 篇幅 | 建议结构 | 章节粒度 | 场景 / 概述配比 | 要点 |
|---|---|---|---|---|
| 短篇（约 1 万字以内） | 起承转合 / 单一事件链；也可用自由结构 | 3–7 段，段即场景 | 几乎全是场景，概述 < 10% | 结构藏在场景顺序里，不显摆；不要塞进三幕的全部情节点 |
| 中篇（1–10 万字） | 三幕 或 起承转合 二选一 | 8–25 章 | 场景为主，次要线可用概述 | 概述用来跳时间，不用来跳关键选择 |
| 长篇（10 万字以上） | 三幕 / 起承转合做骨架 + 单元式自由结构（每章或每单元一次小闭环） | 25–60 章 | 概述压缩，核心场景展开 | 多线用概述统一时间轴，避免同一类场景反复写 |
| 系列 / 单元 | 每篇一次完整弧线 + 全局暗线 | 每篇自足 | 按篇内配比 | 人物弧线跨篇推进，单篇仍要有兑现 |

> **三幕**强调幕的功能与 obligatory 场景（该出现的情节必须出现）；**起承转合**强调因果与转折点（承与转之间是因果，不是并列）；**自由结构**不等于无结构，它把结构放在「重复出现的模式 + 关键处的变奏」上，必须标注变奏点在哪一章。

## 场景与概述的取舍规则

| 判据 | 用场景（scene） | 用概述（summary） |
|---|---|---|
| 转折性质 | 有人做出选择，有对抗 | 状态变了，但过程不产生新选择 |
| 视角人物 | 视角人物的认知或情感变化需要读者亲历 | 变化可以压成一句话交代 |
| 情感浓度 | 高（告别 / 崩溃 / 坦白 / 第一次） | 低（背景、他人故事、前情） |
| 信息密度 | 少量细节，需要被感知 | 大量事实，需要交代 |
| 时间跨度 | 单一时段内连续发生 | 跨日 / 跨季 / 跨年 |
| 篇幅成本 | 高 | 低 |

两条硬规则：

1. **关键选择永远写成场景**，不能用概述——「概述只用于跳过视角人物不在场的部分」。
2. 一章里概述超过三分之一时，问一句：**这章是不是没写什么值得写的？** 答不上来就压缩成背景段，或把某个概述还原成场景。

## 章节大纲模板

```text
第 N 章 <标题>
- 视角：<谁（限知视角，写清这一章能知道什么）>
- 人物目标：<他这一章要拿到什么>
- 阻碍：<什么在挡路（来自人，不来自事故）>
- 转折：<结果如何与预期相反>
- 状态变化：<场景结束时哪个变量被永久改变>
- 出场人物：<...>
- 场景 / 概述：<场景 1 / 概述 / 场景 2>
- 埋 / 收伏笔：<埋 A / 收 B>
- 弧线落点：<哪个人物被推到哪一步>
```

## 人物弧线落点

| 人物 | 触发 | 意识到 | 尝试 | 失败 | 转折 | 代价 | 新常态 | 落点章节 |
|------|------|-------|------|------|------|------|---------|---------|

要求：**转折由代价推动，不由顿悟推动**。人物不是因为想通了才改变，而是因为维持原状已经付不起了。

## 伏笔表与篇幅分配

伏笔表：

| 编号 | 埋（章） | 承诺的内容 | 收（章） | 兑现？ | 状态 |
|------|---------|-----------|---------|-------|------|

> 伏笔的「承诺」必须写清读者被许诺会得到什么；回收时兑现的必须是同一件事，而不是「差不多相关的另一件事」。

篇幅分配（长篇示例，按目标字数等比缩放）：

| 部分 | 建议占比 | 说明 |
|---|---|---|
| 开端：进入日常与打破 | 15–25% | 让读者先拥有一点可失去的东西 |
| 上升：试探与代价升级 | 35–40% | 转折前的准备，预算最多 |
| 中段转折：认知翻转 | 约 50% | 主角对局势的理解被改变 |
| 收紧：代价逼近，退路被削 | 15–20% | 压力来自失去选项 |
| 高潮与收束 | 10–15% | 后果落地，不写总结 |

## 结构自检表

| 检查 | 通过标准 |
|---|---|
| 结构有名有姓 | 明确写出用的是哪套结构，以及为什么适合这个篇幅 |
| 转折源于人物 | 每个转折点都能追溯到某人先前的选择或性格 |
| 弧线可见 | 主角在结尾与开头有可辨认的差别 |
| 章节无空转 | 每章都有目标—阻碍—转折，没有纯过渡章 |
| 场景概述配比合理 | 关键选择都在场景里；概述只跳他不在场的部分 |
| 伏笔闭合 | 每条伏笔都有回收，或明确标注「留白」 |
| 篇幅匹配 | 分配与目标字数匹配，压缩段与展开段清楚 |
| 无说教结尾 | 收束落在后果上，没有总结性独白 |

## 质量检查清单

- [ ] 明确写出了采用的结构与选择理由，并且匹配目标篇幅；
- [ ] 每个转折点都由人物行动触发，没有「事情正好发生了」；
- [ ] 关键选择全部写在场景里，概述只用于跳过视角人物不在场的部分；
- [ ] 每章都有目标、阻碍、转折与状态变化，没有纯过渡章；
- [ ] 人物弧线的转折由代价推动，不是靠顿悟；
- [ ] 伏笔表闭合，每条都写清「承诺了什么」；
- [ ] 篇幅分配合理，压缩段与展开段的理由写明；
- [ ] 结尾落在后果上，没有说教式总结。
