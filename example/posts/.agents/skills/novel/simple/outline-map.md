# 创作脉络与大纲地图（novel/simple）

> 把「大纲 + 正文 + 记忆 + `.workshop`」合成一张可核对的故事地图：结构走到哪一部分、人物弧线停在哪一步、哪些生活细节与关系还没用上、接下来该补什么。

## 用途

- 在开新篇、长期停笔后恢复、交接或复盘时，快速回答「现在写到哪、哪些线还开着、接下来写什么」。
- 把散落在 `outline.md`、正文、人物档案与 `.workshop` 中的信息合成一张结构地图，找出断线、空转与资源闲置。
- 对照结构骨架、场景清单与人物弧线落点，检查当前章节是否在推进主线，还是在重复同一种场景。
- 为 `plot-outline.md` 提供输入：指出下一部分要收的账、可复用的生活细节与需要补的章节。

## 何时使用

- 写完一部分、准备进入下一部分时；
- 写到中段感觉「情节在原地打转」或「人物没有变化」时；
- 长期停笔后恢复写作，需要先找回上下文时；
- 需要向编辑、合作者或读者说明当前进度与后续规划时；
- 发现人物、地点、时间线在正文、记忆与 `.workshop` 之间对不上时。

## 输入

> 记忆、用户记忆、正文、主 `SUMMARY.md`、`.workshop/` 等通用输入见 `.agents/shared/novel-map.md` §1；本表只列本子类型的补充输入。

| 输入 | 说明 | 缺失时 |
|---|---|---|
| 正文 | `posts/`（不存在则 `src/`）下的篇 / 章文件 | 无正文时按「只有大纲」模式分析，明确说明覆盖范围 |
| 分析目标 | 复盘、开新篇、查断线、交接 | 未指定时按「全景复盘 + 下一步建议」执行 |

## 执行步骤

1. **做进度回顾**：按 `AGENTS.md` §0 步骤 3b 输出当前篇 / 章 / 字数与上次更新，作为本次分析的基线。
2. **建结构地图**：按已选结构（起承转合 / 三幕 / 自由结构）标出各部分所在章节、功能与转折点。
3. **对齐主线**：沿「故事核 → 人物目标 → 各部分目标 → 当前章目标」逐级检查，断在哪一级就标在哪一级。
4. **抽支线与伏笔**：从章纲和正文抽出情感线、关系线、生活细节线与伏笔，记录埋点、最近推进、计划回收与状态。
5. **对人物弧线**：对照 `characters.md` 与正文，标出主要人物的起点、当前状态、下一节点与最近出场章。
6. **查场景配比**：统计场景与概述的比例，标出「该写成场景却被概述跳过」的关键选择。
7. **交叉核对 `.workshop`**：按 `.agents/shared/workshop.md` 的契约读取，按 `.agents/shared/novel-map.md` 的「`.workshop` 交叉核对」输出差异。
8. **找缺口**：空转章节、重复场景、断线关系、超期伏笔、只在档案里存在的人物与地点。
9. **给下一步**：输出 1–3 个可执行动作（补章、收线、删重复场景、补设定卡），按优先级排序。
10. **回写记忆**：更新 `outline.md` 的进度与伏笔状态；必要时补 `characters.md`、`world.md`、`continuity.md`。

## 脉络识别口径（普通小说）

| 线索类型 | 从哪里找 | 判定标准 | 断线信号 |
|---|---|---|---|
| 结构骨架 | `outline.md` + 正文章节 | 每部分有功能、转折由人物选择触发 | 中段无转折、结尾仓促 |
| 主线目标 | 故事核、人物目标、章纲 | 每一级都能回答「他想要什么、为什么现在要」 | 章目标与故事核无关 |
| 情感线 | 人物卡 + 关键场景 | 每段关系有推进、回撤或破裂 | 关系状态原地踏步 |
| 生活细节线 | 人物档案 + 场景 | 细节服务于人物与处境，可被后文回收 | 细节只堆砌、不产生作用 |
| 场景 / 概述 | 章节大纲 + 正文 | 关键选择写成场景，概述只跳时间 | 关键选择被概述带过 |
| 人物弧线 | 人物卡 + 出场章 | 每次变化有触发事件与代价 | 长期不出场、顿悟式转变 |
| 伏笔 | 伏笔表 + 正文 | 埋点、推进、回收齐全 | 只埋不收、回收无铺垫 |

## 输出格式

~~~markdown
## 创作进度回顾
（按 `AGENTS.md` §0 步骤 3b 的输出模板）

## 结构地图
```mermaid
flowchart LR
  A[开端 <章段>] --> B[上升 <章段>] --> C[中段转折 <章>] --> D[收紧 <章段>] --> E[高潮与收束 <章段>]
```

## 分部地图
| 部分 | 功能 | 章段 | 转折点 | 当前状态 | 缺口 |
|---|---|---|---|---|---|

## 场景配比
| 章 | 场景数 | 概述数 | 关键选择是否成场景 | 处理建议 |
|---|---|---|---|---|

## 公共块
按 `.agents/shared/novel-map.md` 输出：线索台账、人物弧线、`.workshop` 交叉核对、缺口与风险、下一步、待补输入。
~~~

## 质量检查清单

- [ ] 结构各部分都有功能与转折点，缺失或空转部分已标出；
- [ ] 主线能从故事核一路追到当前章，断点位置明确；
- [ ] 情感线与关系线都有推进或回撤，不是原地踏步；
- [ ] 关键选择都写成了场景，概述只用于跳时间；
- [ ] 已按 `.agents/shared/novel-map.md` 的通用检查清单逐条自检。
