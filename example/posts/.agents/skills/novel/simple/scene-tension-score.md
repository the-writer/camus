# 场景张力评分（novel/simple）

> 以情感张力与道德两难为主要压力来源，给每个场景打分，并给出低分场景的具体处置动作。

## 用途

- 量化节奏，找出塌陷段，同时不把「安静」误判为「没戏」。
- 判断某个场景该保留、合并、删掉还是改写。
- 判断压力是不是来自人物的选择，而不是来自事故。
- 在长篇写作中维持稳定的阅读驱动力。

## 何时使用

- 写完一章自检；
- 读者反馈「中段没意思」「读不下去」时；
- 调整章节顺序、压缩篇幅前；
- 需要判断某个场景是否值得保留时。

## 输入

| 输入 | 说明 | 缺失时 |
|---|---|---|
| 场景文本 | 连续的一段场景 | 必须有 |
| 场景目标 | 该场景在整体中的作用 | 从大纲推断并标注「推断」 |
| 人物档案 | 视角人物的欲望、恐惧、秘密 | 缺失时先做 `character-bible.md` |
| 主题与边界 | 判断什么冲突属于本故事 | 向用户确认或从梗概推断 |

## 执行步骤

1. **切分场景**：按「视角人物 + 时间地点连续」切分，标出序号与篇幅，不按字数硬切。
2. **打分**：对每个场景按六个维度打 0–10 分。
3. **标压力来源**：每个场景标注 1–2 个主要压力来源（外部压力 / 情感压力 / 道德两难 / 沉默与未说出口 / 生活压力）。
4. **画曲线**：把分数连成曲线，标出平台期（连续两场分数接近且偏低）与尖峰。
5. **归因**：对低分场景逐项归因——无目标 / 无阻碍 / 状态未变 / 信息重复 / 节奏拖沓 / 说教 / 靠巧合。
6. **判断是否属于安静场景**：跑「安静场景的价值判断」，命中任一条即判为「低分但必要」，不按塌陷处理。
7. **给处置动作**：每个真塌陷场景给一个**具体**动作（加阻碍 / 合并 / 删 / 换视角 / 后置 / 改写）。
8. **给加压清单**：3–5 条可直接落到某个场景的加压手段。

## 评分维度

| 维度 | 0 分 | 10 分 |
|------|------|--------|
| 目标 | 不知道视角人物这一场要什么 | 目标一句话说清，且有代价 |
| 阻碍 | 没人挡路 | 阻碍具体，来自人的利益与选择，无法轻易绕过 |
| 状态变化 | 结束时与开始时一样 | 至少一个变量被永久改变（钱、关系、身份、时间、健康、某人的看法） |
| 信息增量 | 全是已知信息 | 带来新事实，或让旧信息产生新解读 |
| 情感强度 | 平静无事 | 有明确的情感起伏（压抑、牵挂、难堪、释然） |
| 必要度 | 删掉不影响故事 | 删掉后情节链条断裂 |

> 「情感强度」在现实向小说里指的是**情绪的起伏与未说出口的部分**，不是动作场面。安静但难堪的对话可以给 8 分。

## 压力来源标注

| 来源 | 特征 | 典型场景 |
|---|---|---|
| 外部压力 | 时间、钱、制度、他人要求 | 交房租、办手续、被催 |
| 情感压力 | 牵挂、亏欠、想靠近又不敢 | 多年没联系后的一次通话 |
| 道德两难 | 两个都对的选择，或做了就伤害人 | 保住工作还是替同事说话 |
| 沉默与未说出口 | 该说的话没说，对方也没说 | 两人一起吃饭，全程没提那件事 |
| 生活压力 | 病、累、带娃、照顾老人 | 深夜加班后还要去医院陪床 |

> 若一个场景的主要压力只来自「外部事故」，即使分数高也要复查：冲突若是外力摆布，人物就退回了被推着走的状态。

## 安静场景的价值判断

低分不等于该删。命中以下三条中任意一条，即判为**低分但必要**：

1. **建立生活基线**：它让读者知道人物平时是什么样子，之后的失去才有分量；
2. **给失去做计量**：它先让读者拥有一件东西（一个习惯、一段关系、一件小物件），好让后面失去它；
3. **留白**：它把话停在嘴边，把情绪放在动作里，为后文的爆发蓄压。

三条都不命中，才是真塌陷。判为「低分但必要」时，必须在场景后面写清楚它在结构里的功能。

## 低分场景处置动作

| 症状 | 具体动作 |
|---|---|
| 无目标 | 把目标改写成「他今晚必须拿到 / 必须说出口 / 必须瞒住的一件事」；写不出来就删场景 |
| 无阻碍 | 让一个在场的人做出与他利益相反的选择；阻碍来自人，不来自事故 |
| 状态未变 | 结束时至少改变一个变量：钱、关系、身份、时间、健康、某人对他的看法 |
| 信息重复 | 删掉已知信息，把重复的旧背景压成一句概述 |
| 节奏拖沓 | 合并进相邻场景；把视角人物不在场的部分压成概述 |
| 说教 | 删掉总结句，让后果自己说话 |
| 靠巧合撑场 | 把巧合换成人物早先的选择（他之前答应过谁 / 早先带错了东西 / 早先签过字） |

## 加压手段

| 手段 | 做法 | 适合 |
|---|---|---|
| 加时限 | 明天的截止时间、末班车、账期、断电 | 需要逼出决策 |
| 加成本 | 让失败变贵：押金、误工、伤、关系债、被记住 | 需要升级冲突 |
| 加信息差 | 让读者知道一件角色不知道的事（或反之） | 需要制造焦灼 |
| 收选项 | 拿掉角色的退路（钱不够、车没了、对方改主意） | 需要逼出选择 |
| 换载体 | 让重要信息由物件、身体、沉默承载，而不是台词 | 需要保留体面 |
| 提前埋物 | 让后文的关键物件先出现一次，且看起来无关 | 需要制造回看价值 |
| 换视角 | 从被影响的人写同一件事 | 需要增加层次 |
| 打断 | 让生活琐事打断关键谈话 | 需要改变节奏 |

> 加压不靠事故、不靠巧合、不靠配角突然失忆；一切加压都应从人物已有的处境与承诺里长出来。

## 输出格式

```markdown
## 场景清单
| # | 场景 | 篇幅 | 目标 | 阻碍 | 状态变化 | 信息增量 | 情感强度 | 必要度 | 均分 | 压力来源 |
|---|------|------|------|------|-----------|---------|---------|--------|------|---------|
| 1 | <...> | <...> | 7 | 4 | 6 | 5 | 6 | 8 | 6.0 | 情感压力 / 沉默 |

## 张力曲线
```
1 ── 6.0 ── 7.5 ── 4.0 ── 4.2 ── 9.0
        ▲平台期        ▲尖峰
```

## 低分场景诊断
| 场景 | 均分 | 主因 | 是否安静必要 | 处置动作 |
|------|------|------|-------------|---------|
| 3 | 4.0 | 无阻碍、状态未变 | 否 | 合并进场景 4，并让对手在场 |
| 5 | 3.5 | 无目标 | 是（建立生活基线） | 保留，写明功能：<...> |

## 加压清单
1. 在场景 <N> 中让主角失去 <退路>，代价是 <...>
2. 把 <后文才出现的物件> 提前到场景 <M> 露出
3. <...>

## 结论
<节奏整体判断 + 优先修改的 3 个场景>
```

## 质量检查清单

- [ ] 场景切分基于视角与时空，不是按字数硬切；
- [ ] 每个维度都有依据（可指到具体句子），不是整体印象分；
- [ ] 每个场景都标了主要压力来源；
- [ ] 低分场景先过了「安静场景的价值判断」，被保留的都写明了结构功能；
- [ ] 真塌陷场景给了**具体**处置动作，而不是「再打磨一下」；
- [ ] 加压清单里的每一条都能直接落到某个场景，且不依赖事故或巧合；
- [ ] 曲线图与分数表一致；
- [ ] 没有用分数否定「安静场景」的价值。
