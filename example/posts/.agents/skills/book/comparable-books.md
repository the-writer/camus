# 同类书籍查找与对比（book）

> 给定一本书，找出「同类 / 对照 / 延伸 / 反面」四类书，并说明每本凭什么被推荐。

## 用途

- 读完一本书想读下一本。
- 为书单找出结构化的推荐链，而不是随手列畅销书。
- 为书评提供对照坐标（同类书如何处理同一问题）。
- 扩充个人书架时避免重复。

## 何时使用

- 用户问「类似 X 的书有哪些」；
- 编写主题书单 / 分期推荐时；
- 写书评需要横向比较时。

## 输入

| 输入 | 说明 | 缺失时 |
|---|---|---|
| 参照书 | 书名（尽量带作者） | 必须有 |
| 想要的维度 | 想找「同题材」还是「同方法」还是「反面案例」 | 向用户确认；默认按四类都找 |
| 已读清单 | 避免推荐读过的 | 扫描站读书目 |

## 执行步骤

1. **拆解参照书**：题材、主题、方法、难度、读者收益、时代背景、争议点。
2. **按四类检索**（见下表），每类找 2–3 本。
3. **核验每本书**：确认书名、作者、出版信息、是否确实属于该类（不能凭印象）。
4. **写推荐理由**：每本用一句话说清「与参照书的关系」+「什么时候适合读它」。
5. **排顺序**：按「与参照书接近程度」排序，并标注阅读顺序建议（先读哪个）。
6. **标注前置**：如果后一本需要先读前一本的铺垫，要写明。
7. **补充延伸**：给 1–2 本更高阶或相反立场的书。

## 四类关系

| 类别 | 定义 | 举例（以某本方法书为例） |
|------|------|------------------------|
| 同题材 | 谈同一领域，但立场或路径不同 | 同领域但反对其核心主张的书 |
| 同方法 | 用同样的框架处理不同对象 | 同框架在其它领域的应用 |
| 延伸 | 承接其问题并推进一层 | 更新的研究或后续争议 |
| 反面 | 明确挑战其结论 | 被其批评的学派代表作 |
| 入门 / 进阶 | 难度阶梯 | 同一主题的普及版与学术版 |

## 检索渠道

| 渠道 | 用途 | 注意事项 |
|------|------|---------|
| 图书馆目录 / Open Library | 主题分类、版本、馆藏 | 注意英文分类法与中国分类法不同 |
| 出版社与作者主页 | 新书、系列顺序 | 可能带营销话术 |
| 读书社区（豆瓣、Goodreads、StoryGraph） | 相似推荐、读者反馈 | 热度 ≠ 质量，注意刷评 |
| 学术索引 | 学术书的引用关系与后续讨论 | 仅适用于学术类 |
| 参考书目（该书末尾的注释、延伸阅读） | 作者自己认可的脉络 | 最有价值，优先查 |

## 输出格式

```markdown
## 参照书拆解
| 维度 | 内容 |
|------|------|
| 题材 / 主题 | <...> |
| 方法 | <...> |
| 难度 | <...> |
| 读者收益 | <...> |

## 推荐清单
| 书名 | 作者 | 关系 | 推荐理由 | 适合谁 | 前置阅读 |
|------|------|------|---------|--------|---------|
| <书名> | <作者> | 同题材 | <...> | <...> | 无 |

## 建议顺序
1. <书名> —— 因为 <...>
2. <书名> —— 需要先读 <...>

## 延伸与反面
- <书名>：<为什么值得读 / 挑战了什么>

## 已排除
- <书名> —— <排除原因，例如与已读书重复>

## 待核实
- <书名> —— <需要核对的出版信息或分类>
```

## 质量检查清单

- [ ] 每本推荐都写清了与参照书的具体关系，不是「也很有名」；
- [ ] 书名、作者、出版信息经过核验，没有张冠李戴；
- [ ] 推荐覆盖多个类别，不是同一本书的多个版本；
- [ ] 标注了阅读难度差异与前置阅读关系；
- [ ] 排除了用户已读或与站内已有书单重复的；
- [ ] 无法核实的条目标在「待核实」而不是直接写进清单；
- [ ] 没有把读者评分当成质量结论。

## 参考资料

- [Open Library](https://openlibrary.org/) —— 主题分类与版本信息
- [豆瓣读书](https://book.douban.com/) —— 中文书目、评分与短评
- [Goodreads](https://www.goodreads.com/) —— 读者相似推荐与系列信息
- [BookBrowse](https://www.bookbrowse.com/) —— 按主题聚类的书单
- [标准电子书（Standard Ebooks）](https://standardebooks.org/) —— 公共领域经典，可作为「源头书」参考
- [诺贝尔文学奖](https://www.nobelprize.org/prizes/literature/) —— 经典作品线索
