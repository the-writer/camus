# 阅读计划与进度（book）

> 把「想读的书」变成一份有节奏、有产出、有取舍的读书计划。

## 用途

- 从愿望书单排出可执行的阅读顺序。
- 为长期阅读设定节奏与检查点。
- 处理「读不完」的情况：决定放弃、换读法或降级。

## 何时使用

- 一年 / 季度开始时规划读书；
- 想读的书太多、不知从哪本开始时；
- 计划读某个主题（系统阅读）时；
- 进度落后需要调整时。

## 输入

| 输入 | 说明 | 缺失时 |
|---|---|---|
| 愿望书单 | 想读的书（可多可少） | 必须有 |
| 时间预算 | 每周可投入多少小时 | 向用户确认；没有则按每天 30 分钟估算 |
| 阅读目的 | 技能 / 视野 / 消遣 / 研究 | 向用户确认；决定取舍优先级 |
| 已读记录 | 避免重复 | 扫描站读书目 |

## 执行步骤

1. **清点书单**：按目的分类（专业 / 通识 / 消遣 / 经典），标注每本状态（未读 / 在读 / 读过 / 弃读）。
2. **估时**：按页数与难度估算单本时长（中文约 400–600 字/分钟；难书按 0.7 系数）。
3. **排优先**：按「目的相关度 × 借阅可得性 ÷ 难度」排序，先读「相关 + 好借 + 适中」。
4. **分梯队**：主线（1–2 本，慢读、做笔记）、副线（每周 1 本，快速读）、背景（有空再说）。
5. **排节奏**：给出每周计划与每月检查点。
6. **定义产出**：每本书读完要留下什么（3 条卡片 / 一次分享 / 一篇笔记）。
7. **写放弃规则**：连续两周未读或读到 1/3 仍无收益 → 允许降级或放弃。
8. **建追踪表**：书名、状态、开始 / 结束日期、产出、评分。

## 节奏模型

| 模型 | 适合 | 说明 |
|------|------|------|
| 单线深读 | 有明确研究目标 | 一次只读一本，笔记优先 |
| 主副双线 | 长期阅读 | 主线慢读 + 副线快速读 |
| 主题冲刺 | 补某个领域 | 3–5 本同主题连读，形成对照 |
| 清单驱动 | 消遣阅读 | 按目录推进，不深究 |
| 主题阅读 | 跨领域找模式 | 围绕一个问题同时读多本 |

## 质量检查清单

- [ ] 时间预算是用户确认过的，不是默认套用；
- [ ] 估算时长写明了依据（字数 / 难度系数）；
- [ ] 排序理由可复核（相关度 / 可得性 / 难度）；
- [ ] 每本书都有对应的产出定义；
- [ ] 有明确的放弃 / 降级规则；
- [ ] 计划留有余量（未把全部时间排满）；
- [ ] 与站内已有书单无重复。
