# 结构化读书笔记（book）

> 写出一篇可检索、可复用、他人也能看懂的读书笔记。

## 用途

- 为读完的书留下长期可用的记录。
- 支撑后续的书评、分享与写作。
- 把散落的摘录整理成有观点的文本。

## 何时使用

- 读完一本书（当天或一周内）；
- 主题阅读的一轮结束时；
- 需要为写作积累素材时。

## 输入

| 输入 | 说明 | 缺失时 |
|---|---|---|
| 书与版本 | 标题、作者、译者、版次 | 必须有 |
| 摘录 / 卡片 | 已有素材 | 由用户提供，或先用 `key-idea-extractor.md` 生成 |
| 阅读时长 | 影响笔记深度 | 未指定时按「精读」标准写 |
| 笔记用途 | 私人 / 公开 / 用于写书评 | 向用户确认 |

## 执行步骤

1. **写元信息**：书名、作者、译者、版次、ISBN、阅读日期、阅读时长、评分（说明评分标准）。
2. **一句话概括**：不带评价地复述全书主张。
3. **写结构摘要**：分模块说明每部分讲了什么（用 `book-mapper.md` 的骨架）。
4. **写核心观点**：3–7 条，每条一句话 + 出处。
5. **写「最打动我的」**：具体到某个段落 / 例子 / 数据，并说明为什么。
6. **写「我不认同的」**：给出理由与依据；没有就写「暂无」，不要凑。
7. **写「可迁移到我的什么」**：落到具体场景。
8. **写「读后行动」**：接下来要做的 1–3 件事。
9. **写「留给以后的问题」**：读完后仍没解决的疑问。

## 笔记模板

```markdown
---
title: 《书名》读书笔记
tags: [读书笔记, <主题>]
---

# 《书名》

> <一句话概括，不带评价>

## 元信息
| 项 | 值 |
|----|-----|
| 作者 / 译者 | <...> |
| 版次 / 出版年 | <...> |
| ISBN | <...> |
| 阅读日期 | <...> |
| 阅读时长 | <...> |
| 评分 | <.../5>（标准：<...>） |

## 结构摘要
### <部分一>
<...>

## 核心观点
1. <观点> —— 出处：<...>
2. ...

## 最打动我的
> <原文短引>

<为什么>

## 我不认同的
- <作者观点> —— 我的理由：<...>

## 可迁移到我的什么
- <场景> —— <怎么做>

## 读后行动
- [ ] <...>

## 留给以后的问题
- <...>
```

## 质量检查清单

- [ ] 元信息完整，版本写明（不同译本内容差别大）；
- [ ] 摘引控制在必要长度，且标明出处；
- [ ] 概括与评价分开（先复述，再判断）；
- [ ] 核心观点不超过 7 条；
- [ ] 「不认同」部分有理由，或明确写「暂无」；
- [ ] 行动项具体到可勾选；
- [ ] 笔记脱离原书也能读懂（不依赖上下文指代）。
