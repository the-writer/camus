# 核心观点与读书卡片（book）

> 从一本书中提炼 5–15 条可复用的观点，做成带出处与适用边界的卡片。

## 用途

- 把「读过了」变成「能复述、能应用」。
- 为笔记系统（卡片盒 / 双链笔记）提供可迁移的原子卡片。
- 为书评、分享、演讲准备材料。

## 何时使用

- 读完一本书需要沉淀时；
- 写书评需要提炼观点时；
- 建立个人知识库时；
- 读书会上分享前的准备。

## 输入

| 输入 | 说明 | 缺失时 |
|---|---|---|
| 书或章节 | 来源 | 必须有 |
| 原文摘录 | 可标注页码/位置 | 缺失时用笔记代替，但标注「据笔记」 |
| 读者目的 | 想用于什么场景 | 向用户确认 |

## 执行步骤

1. **筛选**：只保留「以后还会用得上」的观点；一句漂亮话但没有可操作性的一律丢弃。
2. **改写为自述**：用自己的话重写，禁止照抄原句（避免变成摘抄本）。
3. **保留出处**：标注章节 / 页码 / 段落位置。
4. **补适用边界**：这个观点在什么条件下成立？什么时候会失效？
5. **补反例**：举一个自己或他人遇到的、与之矛盾的情形。
6. **配行动**：每条卡片给一个「可以立刻做什么」的小动作。
7. **合并去重**：意思相同的卡片合并，保留最强的那条表述。

## 卡片模板

```markdown
> **观点**：<用自己的话，一句话>
> **出处**：<书名 / 第几章 / 页码>
> **适用**：<在什么前提下成立>
> **失效**：<什么时候不成立>
> **反例**：<一个具体情形>
> **行动**：<可以立刻做的一件事>
```

## 质量检查清单

- [ ] 全部用自己的话，没有整句照抄；
- [ ] 每条都有可核对的位置标注；
- [ ] 每条都写了适用前提与失效条件；
- [ ] 每条都有至少一个反例或边界情形；
- [ ] 每条都能转成一个具体动作；
- [ ] 数量控制在 5–15 条（超过说明没筛选）；
- [ ] 观点之间不重复。
