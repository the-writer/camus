# 书籍地图（book）

> 为一本书画出结构骨架：章节脉络、论点分布、作者的方法与作者想让你相信什么。

## 用途

- 读完一本书后快速回溯结构与论点。
- 判断一本书值不值得读、该怎么读。
- 为书评与读书笔记提供骨架，避免变成流水账。
- 把一本书拆成可复用的知识模块。

## 何时使用

- 读完后整理；
- 写书评或长笔记前；
- 需要向他人介绍这本书时；
- 决定是否读一本新书时（先看目录与序言）。

## 输入

| 输入 | 说明 | 缺失时 |
|---|---|---|
| 书名 / 版本 | 精确到版本（译者、版次影响内容） | 必须有 |
| 目录 | 章节结构 | 从书中抄录 |
| 正文或笔记 | 内容细节 | 由用户提供的笔记、摘录或原文 |
| 读者目的 | 想解决什么问题 | 向用户确认 |

## 执行步骤

1. **定版本信息**：书名、作者、译者、出版社、版次、ISBN、阅读语言。
2. **抄目录**：逐章列出标题，不做评价。
3. **写一句话总论**：这本书在解决什么问题 / 主张什么。
4. **标论点位置**：每个核心论点出现在第几部分，是否有例子与证据。
5. **分模块**：把目录归为 3–6 个主题模块，标出各模块的页数占比。
6. **找作者的方法**：作者用什么方式论证（案例、数据、实验、类比、叙事）。
7. **标可迁移部分**：哪些结论可以直接用在自己身上 / 自己的项目上。
8. **标存疑部分**：与自己的经验冲突或证据不足之处。

## 质量检查清单

- [ ] 版本信息完整（不同译本差别很大）；
- [ ] 目录先原样抄录，再归纳，没有边抄边评价；
- [ ] 每个核心论点都标了位置；
- [ ] 论证方式与证据类型已区分（案例 ≠ 数据 ≠ 比喻）；
- [ ] 主题模块覆盖全书，没有遗漏章节；
- [ ] 可迁移结论写明了适用边界；
- [ ] 存疑部分基于证据而非个人偏好。

- [开放图书馆（Open Library）](https://openlibrary.org/) —— 版本、译者与目录信息核对
- [豆瓣读书](https://book.douban.com/) —— 中文版书目信息与版本对照
