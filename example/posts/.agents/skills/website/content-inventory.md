# 内容盘点与信息架构（website）

> 把站点现有页面摊平分类，判断哪些该留、该合并、该重写、该下沉。

## 用途

- 为一个内容混乱的站点建立清晰结构。
- 判断「产品页 / 说明页 / 文章 / FAQ」的分界。
- 发现重复页面、空页面、无入口页面。
- 为导航与内链提供结构依据。

## 何时使用

- 站点改版、合并栏目之前；
- 内容增长到互相打架时；
- 接手一个既有站点做梳理；
- 定期（每季度）做一次结构体检。

## 输入

| 输入 | 说明 | 缺失时 |
|---|---|---|
| 页面清单 | 路径、标题、字数、更新时间、来源 | 扫描内容目录生成 |
| 站点目标 | 想让用户完成什么 | 读主 `SUMMARY.md`；缺失时向用户索取 |
| 用户画像 | 主要访客与他们的任务 | 向用户索取 1–2 句 |
| 现有数据 | 访问量、搜索词、跳出页 | 有则用；没有则标注「无数据，按推断」 |

## 执行步骤

1. **建页面台账**：每页一行 —— 路径 / 标题 / 类型 / 字数 / 最近更新 / 入链数 / 出链数 / 目标 / 状态。
2. **判定页面类型**：按 Diátaxis 的四象限归类 —— 教程 / 参考 / 说明 / 讨论；产品页另立「说服型」。
3. **查重叠**：标题相似、URL 相似、主题重叠的页面两两配对，标注重复度。
4. **查孤儿与死路**：无入链页面、无出链页面、导航里点不到也搜不到的页面。
5. **对齐用户任务**：每个页面标注它服务的用户任务；无法对应任何任务的页面列为「待删或待合并」。
6. **定层级**：用三层结构（首页 / 栏目 / 页面）表达，不用超过三层。
7. **出处置表**：每页给一个动作 —— 保留 / 合并 / 重写 / 下沉 / 删除 / 待补。

## 页面类型判定

| 类型 | 回答的问题 | 典型特征 | 处置 |
|------|-----------|---------|------|
| 教程 Tutorial | 我照着做能完成吗 | 有顺序、前置条件、步骤 | 保留，步骤化 |
| 参考 Reference | 我要查某个参数是什么 | 按条目组织，可跳读 | 保留，表格化 |
| 说明 Explanation | 为什么是这样 | 讲原理、背景 | 保留，控制在 1–2 屏 |
| 讨论 Discussion | 业界怎么想 | 有观点、案例 | 保留为文章 |
| 说服型 Landing | 你为什么选我们 | 有 CTA、卖点 | 保留，聚焦单页 |
| 混合型 | 什么都想说 | — | 拆成 2–3 页 |

## 处置动作

| 动作 | 条件 | 后续 |
|------|------|------|
| 保留 | 有人用、有任务、内容准确 | 定期更新 |
| 合并 | 与其它页重复度 > 60% | 保留信息更全的一页，旧页做重定向 |
| 重写 | 结构对但表达差 / 结论过时 | 用 `copy-rewrite.md` 重写 |
| 下沉 | 重要但非主线 | 移到二级页面并加入口 |
| 删除 | 无入链、无任务、长期无更新 | 删除并从站点地图移除 |
| 待补 | 有入口但内容为空 | 补内容或标注「计划中」 |

## 输出格式

```markdown
## 站点目标
<一句话：服务谁 / 解决什么 / 期望用户完成什么>

## 页面台账
| 路径 | 标题 | 类型 | 字数 | 最近更新 | 入链 | 出链 | 用户任务 | 状态 |
|------|------|------|------|---------|------|------|---------|------|
| /pricing | 定价 | 说服型 | 620 | 2026-03-11 | 12 | 3 | 判断是否值得买 | 保留 |

## 重叠页面
| 页面 A | 页面 B | 重复度 | 建议 |
|--------|--------|--------|------|
| /guide | /docs/guide | 75% | 合并到 /guide |

## 孤儿与死路
- 孤儿页（无入链）：<...>
- 死路页（无出链）：<...>

## 目标结构
```
首页
├── 栏目 A
│   ├── /a/1
│   └── /a/2
└── 栏目 B
```

| 页面 | 动作 | 理由 | 负责人 | 期限 |
|------|------|------|-------|------|
| /guide | 合并到 /docs | 重合 75% | <...> | <...> |
```

## 质量检查清单

- [ ] 台账覆盖全部页面，含更新日期与入链数；
- [ ] 每个页面都归了类型，且类型互斥（混合型已标出）；
- [ ] 重叠判定给出了重复度与合并方向；
- [ ] 孤儿页 / 死路页都列了出来；
- [ ] 每个页面都对应一个真实的用户任务；
- [ ] 目标结构不超过三层；
- [ ] 处置动作具体到页面，未使用「优化一下」这类空话。
