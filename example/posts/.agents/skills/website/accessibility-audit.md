# 可访问性审查（website）

> 按 WCAG 2.2 逐条核对页面，输出「问题 + 位置 + 修法 + 验收方法」清单。

## 用途

- 给站点做可访问性体检并留下可复查的记录。
- 在改版前发现会伤害部分用户的设计。
- 满足合规要求，同时提升所有用户的可用性。

## 何时使用

- 主题改版、新页面模板上线前；
- 收到无障碍投诉或审核要求时；
- 每季度做一次回归检查。

## 输入

| 输入 | 说明 | 缺失时 |
|---|---|---|
| 页面地址或模板文件 | 待审对象 | 必须有 |
| 关键用户流程 | 最重要的 1–3 个任务 | 未指定时按「首屏导航 → 主要操作 → 提交」推断 |
| 技术栈 | 决定能否用语义化标签 | 从源码或页面结构判断 |

## 执行步骤

1. **确定范围**：列出待审页面与关键流程。
2. **键盘走查**：只用键盘完成关键流程，记录焦点顺序、可见焦点、是否有焦点陷阱。
3. **逐条核对**：按下方 A / AA 清单检查，标注 通过 / 失败 / 不适用。
4. **读屏抽测**：用屏幕阅读器走一遍首屏与主要表单。
5. **对比度检查**：正文 4.5:1、大字 3:1、界面组件与图形 3:1。
6. **记录问题**：每条给出 准则号 / 位置 / 现象 / 影响人群 / 修法 / 验收方法。
7. **排优先级**：按「影响人数 × 阻断程度」排序，先修阻断型。

## 核心准则清单（A / AA）

| 准则 | 要求 | 快速检查 |
|------|------|---------|
| 1.1.1 非文本内容 | 图片、图标有等效替代文本；装饰性图片标 `alt=""` | 逐图查看 `alt` |
| 1.3.1 信息与关系 | 用正确标签、列表、表单标签表达结构 | 查看大纲与标签 |
| 1.3.2 有意义的顺序 | 阅读顺序与视觉顺序一致 | 读屏试听 |
| 1.3.3 感官特征 | 不用「点击右上角红色按钮」指代 | 搜索方位词 |
| 1.4.1 只用颜色 | 颜色不是唯一信息载体 | 灰度模式查看 |
| 1.4.3 对比度（最小） | 正文 4.5:1 / 大字 3:1 | 对比度工具 |
| 1.4.4 调整文字大小 | 放大到 200% 不丢内容 | 浏览器缩放 |
| 1.4.10 回流 | 320px 宽下不出现双向滚动 | 窄视口测试 |
| 1.4.11 非文本对比度 | 控件边框、图形 3:1 | 对比度工具 |
| 2.1.1 键盘 | 所有功能可用键盘完成 | 键盘走查 |
| 2.1.2 无键盘陷阱 | 能离开任何组件 | Tab 走查 |
| 2.4.1 跳过区块 | 提供跳到主内容链接 | 首页检查 |
| 2.4.2 页面标题 | 每页有描述性标题 | 逐页看标签页 |
| 2.4.3 焦点顺序 | 焦点顺序符合阅读逻辑 | 键盘走查 |
| 2.4.4 链接目的（在上下文中） | 链接文本能独立说明去向 | 通读链接 |
| 2.4.6 标题与标签 | 标题描述主题 | 通读标题 |
| 2.4.7 焦点可见 | 焦点有明显指示 | 键盘走查 |
| 2.4.11 焦点不被遮挡（最小） | 焦点元素不被吸顶元素遮住 | 键盘走查 |
| 2.5.8 目标尺寸（最小） | 指针目标 ≥ 24×24 CSS 像素 | 量尺寸 |
| 3.1.1 页面语言 | 声明 `lang` | 看源码 |
| 3.2.3 一致的导航 | 导航在页面间位置一致 | 跨页比对 |
| 3.3.1 错误识别 | 错误被标识并说明如何修正 | 提交无效表单 |
| 3.3.2 标签或说明 | 输入项有标签或说明 | 表单走查 |
| 3.3.7 冗余输入 | 同流程中不要求重复输入 | 走查多步表单 |
| 4.1.2 名称角色值 | 组件有可编程确定的名称、角色、状态 | 查看 DOM / 用工具扫描 |

## 记录模板

```markdown
## 范围
- 页面：<...>　关键流程：<...>　审查环境：<浏览器 / 辅助技术>

## 结论
- 失败项：<n>　部分通过：<n>　通过：<n>　不适用：<n>

## 问题清单
| 级别 | 准则 | 页面 | 现象 | 影响人群 | 修法 | 验收方法 |
|------|------|------|------|---------|------|---------|
| 阻断 | 2.1.1 | /pricing | 定价表只能用鼠标横向滚动 | 键盘用户 | 改为响应式堆叠 | 键盘可完整读取所有价格 |

## 通过项摘要
- <准则>：<如何验证>

## 待复核
- <需要读屏实测的项>
```

## 质量检查清单

- [ ] 每条问题都标注了 WCAG 准则号；
- [ ] 修法具体到元素与属性（不是「优化对比度」）；
- [ ] 每条问题都有可复现的验收方法；
- [ ] 键盘走查已实际完成（不是推测）；
- [ ] 装饰性图片与信息性图片分别处理；
- [ ] 不适用项写明理由；
- [ ] 未把「符合规范」与「好用」混为一谈，两者是不同结论。
