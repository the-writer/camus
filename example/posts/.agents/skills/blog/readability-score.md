# 可读性与质量评分（blog）

> 用可计算的指标给稿件打分，并给出**可执行的改写清单**，而不是一句「读起来还行」。

## 用途

- 在发布前量化判断「读者会不会中途退出」。
- 横向比较多版标题 / 开头 / 摘要的文本质量。
- 为改写排优先级：先改最影响阅读的部分。

## 何时使用

- 发布前的最后一道检查；
- 需要比较两版文稿；
- 判断长文是否需要拆分或加小标题；
- 建立团队内部的稿件准入标准。

## 输入

| 输入 | 说明 | 缺失时 |
|---|---|---|
| 正文文本 | 待评稿件 | 必须有 |
| 目标读者水平 | 决定目标分数区间 | 未指定时按「专业读者 + 泛读者混合」给两套目标 |
| 语种 | 决定用哪套公式 | 中文内容使用「中文适配指标」 |

## 执行步骤

1. **统计基础量**：总词数（或总字符数）、句数、段落数、平均段长。
2. **标注长句**：标出超过阈值的句子（英文 > 25 词 / 中文 > 45 字）。
3. **标注被动与弱动词**：中文「被 / 受到 / 进行 / 加以 / 得到」，英文 `be + past participle`。
4. **计算指标**（按语种选，见下）。
5. **给总分与分项**：每个分项 0–10，加权成 100 分制。
6. **产出改写清单**：按「影响阅读的程度」排序，每条给出「原句 → 建议改写」。
7. **给结论**：一句话结论 + 是否建议发布。

## 指标与算法

### 英文文本

| 指标 | 公式 | 含义 |
|---|---|---|
| Flesch Reading Ease | `206.835 − 1.015 × (词数/句数) − 84.6 × (音节数/词数)` | 越高越易读，60–70 适合大众 |
| Flesch-Kincaid Grade | `0.39 × (词数/句数) + 11.8 × (音节数/词数) − 15.59` | 对应美国年级 |
| Gunning Fog | `0.4 × [(词数/句数) + 100 × (复杂词占比)]` | 复杂词 = 3 音节及以上 |
| Coleman-Liau | `0.0588L − 0.296S − 15.8`，L = 每 100 词平均字母数，S = 每 100 词平均句数 | 对长单词更敏感 |
| SMOG | `1.0430 × √(多音节词数 × 30 / 句数) + 3.1291` | 需 ≥ 30 句才稳定 |

### 中文文本（西文公式不适用，改用下列指标）

| 指标 | 算法 | 阈值参考 |
|---|---|---|
| 平均句长 | 总字符数 / 句数 | 15–30 字为舒适区 |
| 长句占比 | > 45 字的句子占比 | < 20% |
| 平均段长 | 总字符数 / 段落数 | 3–5 句一段 |
| 术语密度 | 专有名词 / 专业术语 / 字符数 | 首次出现需解释 |
| 虚词占比 | 「的 / 了 / 是 / 在 / 和」等占比 | 过高说明句子松散 |
| 口语化标记 | 成语、四字格、网络语占比 | 视调性决定，不设硬阈值 |

## 评分卡（100 分）

| 分项 | 权重 | 评分要点 |
|---|---|---|
| 句子清晰度 | 25 | 长句比例、平均句长、是否需要回读 |
| 段落结构 | 20 | 段长、首句是否点题、小标题是否有效 |
| 术语处理 | 15 | 术语首次出现是否解释、是否全文一致 |
| 信息密度 | 20 | 有效信息 / 总字数，有无凑字数的铺垫 |
| 可扫描性 | 10 | 列表、表格、加粗是否用在真正需要扫读处 |
| 开头与结尾 | 10 | 首屏是否给出主张与收益，结尾是否落点 |

## 输出格式

```markdown
## 基础统计
- 词/字数：<...>　句数：<...>　段落数：<...>　平均段长：<...>

## 指标
| 指标 | 数值 | 目标 | 判定 |
|------|------|------|------|
| <...> | <...> | <...> | 通过 / 偏低 / 偏高 |

## 评分
| 分项 | 得分 | 依据 |
|------|------|------|
| 句子清晰度 | 18/25 | <...> |
...
总分：<...>/100

## 改写清单（按优先级）
1. 原文：<原句>
   建议：<改写后>
   原因：<长度 / 被动 / 术语 / 冗余>

## 结论
<一句话结论 + 是否建议发布>
```

## 质量检查清单

- [ ] 统计量是实际计算的，不是估计的；
- [ ] 中文稿件没有硬套 Flesch 等西文公式；
- [ ] 改写清单每条都给出可直接替换的句子；
- [ ] 分数与改写清单有对应关系（低分项一定有改写条目）；
- [ ] 结论明确，不要「视情况而定」；
- [ ] 未为了分数牺牲专业准确性（术语该长就长）。
