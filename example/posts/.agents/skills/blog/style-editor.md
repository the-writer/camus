# 文风审校与「AI 味」清理（blog）

> 用一张可执行的审校表逐句过稿，去掉套话、冗余与机器腔，保留作者本人的声音。

## 用途

- 把「读着像 AI 写的」改回「像人写的」。
- 统一术语、标点、数字与专有名词写法。
- 在不改变事实的前提下提升文字的准确度与节奏。

## 何时使用

- 稿件由 AI 起草或大段改写后；
- 发布前终审；
- 需要统一全站文风；
- 反馈里出现「太水」「太套话」「读不下去」。

## 输入

| 输入 | 说明 | 缺失时 |
|---|---|---|
| 待审稿件 | 全文 | 必须有 |
| 站点语气基线 | 既有文章的语气样本 | 扫描 `posts/` 推断 |
| 术语表 / 人名地名表 | 专有名词写法 | 从稿件中抽取候选，交用户确认 |

## 执行步骤

1. **通读标注**：按四类标记 —— `【套话】` `【冗余】` `【AI腔】` `【事实待核】`。
2. **清理套话**：删掉不承载信息的固定句式。
3. **去 AI 腔**：处理过度工整的三段式、滥用连接词、空泛形容词与万能结尾。
4. **拆长句**：超过阈值的句子拆成 2 句，保留原意与语气。
5. **统一术语**：按术语表统一写法；首次出现的缩写给出全称。
6. **核对事实**：所有数字、引文、书名、版本号、日期逐条列出，标注可核实来源；无法核实的标 `【待核实】`。
7. **朗读检查**：把改写后的关键段念一遍，标出「念不顺」的地方。
8. **输出对照稿**：左原文右改写，附问题统计。

## 高频问题清单

### 套话（直接删）

「在当今社会」「随着……的快速发展」「众所周知」「不言而喻」「总的来说」「综上所述」「让我们一起」「本文将详细介绍」「希望这篇文章能帮到你」「欢迎在评论区留言」。

### AI 腔特征

| 特征 | 表现 | 处理 |
|---|---|---|
| 过度工整 | 每段都是 3 条、句长相近、句式同构 | 打散节奏，长短句混排，删掉凑数的第三条 |
| 万能连接词 | 首先 / 其次 / 再次 / 最后 / 与此同时 / 总而言之 | 换成具体动作或直接删 |
| 空泛形容词 | 强大、显著、深刻、全方位、多维度 | 换成可验证的事实或数字 |
| 名词化 | 「进行优化」「实现了提升」「具有……性」 | 还原成动词短语 |
| 伪具体 | 「据统计」「研究表明」但无出处 | 删除或补来源，缺来源标 `【待核实】` |
| 情感填充 | 「令人惊叹的是」「毫无疑问」 | 删掉，让事实自己说话 |
| 万能结尾 | 「让我们一起期待……」 | 换成可执行的下一步或戛然而止 |
| 破折号滥用 | 一段多个 `——` | 保留真正需要停顿的，其余改逗号或句号 |
| 括号塞满 | 一句话里三四个括号 | 拆句或移到下文说明 |

### 技术性检查

- 中英文之间有空格；中文与数字/单位之间有空格；
- 不用 `～`、`~` 混用；区间用 `–` 或 `至`；
- 中文用全角标点，代码/路径/命令用半角；
- 代码、命令、路径、参数名加反引号；
- 百分号、数值与单位写法全站一致（如 `20%` vs `20 %` 择一）。

## 输出格式

```markdown
## 问题统计
| 类别 | 数量 | 说明 |
|------|------|------|
| 套话 | 12 | <...> |
| 冗余 | 8 | <...> |
| AI 腔 | 15 | <...> |
| 待核实事实 | 3 | <...> |

## 对照修改
| # | 原文 | 改写 | 问题类型 |
|---|------|------|---------|
| 1 | <...> | <...> | 套话 |

## 术语表
| 术语 | 统一写法 | 首次出现处 |
|------|---------|-----------|

## 待核实
- <事实 1> —— <出现在第几段 / 需要什么来源>

## 朗读不顺处
- <段落> —— <原因与建议>
```

## 质量检查清单

- [ ] 每处改动都标了问题类型；
- [ ] 没有为了「像人写的」而引入事实错误；
- [ ] 删除套话后句子仍然完整通顺；
- [ ] 事实类陈述全部有来源或标了 `【待核实】`；
- [ ] 术语、标点、空格的写法在全稿统一；
- [ ] 作者原有的个人腔调被保留（不要改得只剩通用腔）；
- [ ] 改动比例合理：审校不是重写，若改动超过全文 30% 需要先与作者确认方向。
